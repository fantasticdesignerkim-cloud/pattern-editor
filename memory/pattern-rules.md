## 1. «맞댄다» 계열 도해(P.157·159·160·161)를 읽는 순서 — **소매 Ⓒ 이번 사례에서 확정된 읽는 법**

> 아래는 **소매 Ⓒ(P.41 하단) 재해석에서 김님이 확정한 사례**를 증류한 것이다. 앞 EL 절개·소매구 연장 같은 세부는 **Ⓒ 이번 사례의 범위**이며,
> 다른 맞댐 작업의 일반 법칙으로 쓰지 않는다. 다른 작업에 적용하려면 그 작업의 도해를 같은 순서로 다시 읽고 김님 확인을 받는다.

1. **Ⓐ 원형 위에 완성 가정선을 먼저 그린다.** 본문이 «완성된 모양을 가정하여 그린 뒤 1장으로 만든다» 라고 순서를 정한다. 이 순서를 생략하지 않는다.
2. **선 역할을 구분한다**: 원형선(Ⓐ 윤곽·얇은 기준선) / 완성 가정선(굵은 꺾은선) / **실제 절개선**(굵은 가로 EL — 김님 확정) /
   맞대는 대응 / 봉제 다트(뒤 V) / 길이 보정 표시(⊠). **선의 역할과 제도 단계를 구분하고 혼동하지 않는다**(한 선이 절개선과 봉제선처럼 여러 역할을 겸할 수 있다 — 어느 단계에서 어느 역할로 쓰는지를 분명히 한다).
3. **같은 ◎ / 채운 ●◎ 끼리 맞댄다.** 맞대는 곳이 둘 이상이면 다른 표시를 쓰고, 가까운 파트부터 처리한다(P.159).
4. **강체 조각 이동**: 맞대는 두 변을 일치시키는 결과로 이동이 정해진다 — **회전중심(힌지)을 먼저 고르지 않는다.**
5. **겹침 · 반동 · 길이 보정**: P.161 은 «닫는다·벌린다» 를 한 세트의 **제도 연산**으로 설명한다(조각 구성 조건에 따라 지정한 곳이 벌어진다). Ⓒ 에서는 EL 위를 맞대면 아래가 벌어진 뒤 V 로 읽었다.
   겹친 길이만큼 소매구 쪽을 **연장**해 옆선을 맞추는 것은 **Ⓒ 이번 사례의 김님 확정**이다(조각 자체를 늘리지 않는다).
6. **현재 단일 외곽으로 검증**: 틈·겹침·외곽 연속·옆선 길이를 본다. 길이만 맞추려고 임의로 형상을 바꾸는 우회는 쓰지 않는다.
   **소매 Ⓒ 이번 사례(2026-10-08 김님 최신 확정)**: 출발 소매산(Ⓐ)은 맞댐으로 조금 찌그러지고, 그 결과를 국소 꺾임 연결 목적으로 자연스럽게 다시 그린다 — Ⓐ 복사도 아니고 길이만 맞추는 변형도 아니다.
   재제도는 잔부 보존·끝점 정합·접선 연속·자기교차 없음·길이/이세 독립 실측으로 검증한다.

## 2. 함정 (실제로 틀렸던 것)

- **원형 수직축을 완성 경계로 오인**했다 → 앞 하부 조각 경계에 큰 빈틈(비교 시안 v1). 실제 경계는 **EL 에서 소매중심에 가까운 굵은 선을
  교차점 너머까지 따라간 선**이고(항상 왼쪽 선이 아님), 이걸 쓰면 빈틈이 도해 정합 수준에서 해소됐다(v2). 원인 «후보»이며 증명은 아니다.
- 계산값·비율을 먼저 박고 도해를 끼워 맞췄다(1.49 겹침 · 최종 호 길이 1:2:1 강제 · 전체 회전 + fairing · 가정값 wE/nH/φ) → **현재 해석으로 대체된 가정**이다.
- 판독한 도해 픽셀 수치(d 단위, ±2 d)를 설계값·공차로 복사하지 않는다 — 그림 판독용일 뿐이다.

## 3. 미확정 판단은 조회한다

- 이 문서는 진행·미완료 상태를 복제하지 않는다. **무엇이 아직 결정되지 않았는지**(예: Ⓐ 소매산 유지와 맞댐 윤곽의 관계, 기호 정의·정확한 제도 치수)는
  [../docs/book/P041.md](../docs/book/P041.md) § Ⓒ 재해석의 «미확정» 과 [../docs/STATUS.md](../docs/STATUS.md) 를 **그때 조회**한다.
- 결정되지 않은 항목은 구현·임의 선택 금지, 김님 결정 후에만 진행한다.
