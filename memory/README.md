## 2. 경계 — 무엇이 CLAUDE.md 이고 무엇이 memory 인가

판정 질문: **"코드가 바뀌면 틀려질 수 있는 문장인가?"**

- 아니오 (위반하면 사고가 나거나 사용자가 확정한 규칙) → **CLAUDE.md**(헌법). memory 는 [decisions.md](decisions.md) 로 **색인만** 한다.
- 예 (함수 목록·상수·구조·함정·실측) → **memory**. memory 의 코드 사실은 **특정 HEAD 에서 관찰한 기록**일 뿐 규범이 아니다.

**불일치 처리 규칙** — memory 와 코드(또는 문서끼리)가 어긋나도 **코드가 자동으로 이기지 않고, memory·코드 어느 쪽도 자동으로 고치지 않는다.**
코드는 현재 구현의 관찰 근거이지 규범적 결정의 상위가 아니다. 어긋남을 발견하면:

1. 관련 🔒/🏛 결정([decisions.md](decisions.md) → 원문)과 테스트(shape 골든·하네스, [../docs/TESTING.md](../docs/TESTING.md))를 대조한다.
2. **버그**(코드가 결정·테스트를 어김)인지 **문서 노후화**(결정·테스트는 현재 코드를 뒷받침하는데 memory 가 낡음)인지 **판단 불가**(결정·테스트가 침묵)인지 분류한다.
3. 결과를 사용자에게 **보고**한다(대조한 결정 ID·테스트·분류 근거 포함). 수정·`superseded` 처리는 사용자 승인 후에만 한다 — 🔒 항목이 걸리면 사용자 확인이 필수다.

## 3. 링크 규칙 (중복 방지)

1. **링크 우선, 복사 금지.** 한 사실의 본문은 한 곳에만 둔다. 다른 곳은 `source:` / `see:` 링크만 쓴다.
2. 모든 항목·절은 **`source:`**(코드 함수명 / 문서 § 제목 / 커밋 해시)를 가진다. source 없는 문장은 쓰지 않는다.
3. **교재 수치는 memory 에 쓰지 않는다.** 단일 진실은 `js/collarPresets.js` 레코드와 [`docs/book/PNNN.md`](../docs/book/INDEX.md) 다.
   원형 관련 항목은 출처 라벨 **[학교책] / [패턴학교]** 를 반드시 붙인다([book/README.md](../docs/book/README.md)).
4. **연대기는 옮기지 않는다.** "왜 이렇게 됐나"는 `docs/history/` 로 링크한다. memory 는 **현재형**만 쓴다.
5. **앵커는 섹션 제목 접두어**로 건다(줄 번호는 힌트일 뿐). 제목이 바뀌면 새 행을 추가하고 옛 앵커는 이력으로 둔다.
6. 코드 사실(함수명·상수값)에는 `verified-at: HEAD <해시>` 를 적는다. 그 이후 코드가 바뀌었는지는 읽는 쪽이 `git log <해시>..HEAD -- js/<파일>` 로 확인한다.

## 4. 잠금·superseded·자동 정리 금지

- 사용자 확정 결정(🔒)과 CLAUDE.md 선언 결정(🏛)은 **삭제·병합·재서술·이동·압축 금지**. 목록과 규칙은 [decisions.md](decisions.md).
- 대체는 삭제가 아니라 **상태 변경 로그에 행을 추가**한다(`superseded_by` 필수, 원문 보존). 🔒 의 변경은 사용자 확인 후에만.
- 자동·반자동 정리는 **제안(diff)만** 낸다. 적용은 사람이 한다. 기존 `CLAUDE.md`·`docs/**`·코드·테스트는 이 도입 범위에서 **수정하지 않는다**.
