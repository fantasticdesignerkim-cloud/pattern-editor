# P.34 — 요크 이음선 ③ 변형 Ⓤ «밑단에서 1cm 추가, 이음선을 넣고 앞은 AH 다트를 닫아 이음선에서 벌리고, 뒤 중심에 개더 분량을 추가»

> **출처: [패턴학교]** P.34 (PDF index 33). 판독일 2026-10-02, `books/pages/p034.jpg` 읽기 전용(도해 크롭 3장 확인).
> 원본에서 직접 읽히는 것만 적는다. 수치의 단일 진실은 `js/bodicePresets.js` 레코드(Ⓤ 는 아직 `pending-op`).
> **상태: 2026-10-02 구현됨**(`designYokeSeam.splitU` · `bunka-bodice-U` · `yokeSeamUCheck.js`). 김님 확정: 어깨 요크 = **뒤 어깨 다트를 먼저 닫아 붙이고, 그다음 앞 요크를 어깨선으로 붙인 한 장**.
> **김님 최종 확정(2026-10-02, P.34·P.35 도해 대조) — 앞 제도 순서**: ① 앞 어깨선과 평행한 선을 어깨선에서 **수직거리 6cm** 내려 이음선을 만든다 → ② 이음선 양 끝(목둘레 교점↔진동선 교점) 사이
> **호길이 정확히 1/2점** 을 잡는다 → ③ 그 점과 BP 를 **직선**으로 잇는다(절개선). **BP→이음선 구간은 연직 투영이 아니다**(7a09fba 의 구현 오류, 이 확정으로 교체) → ④ BP 아래 구간이 필요한 **Ⓥ 에서만**
> 앞중심선과 평행한 수직선이 맞다(Ⓤ 와 혼동 금지) → ⑤ 앞 이음선 양 끝 2cm 는 개더 제외 구간. 이 규칙에서 쐐기 폭/(이음선−4) = 0.601 로 캡션 «● 의 약 0.6배» 와 부합하고, 절개선은 연직에서
> 진동 쪽으로 약 5.4° 기울어 도해(Ⓤ 4.5°·Ⓥ 5.3°)와도 맞는다(결과 비율 — 게이트 아님).
> 어깨 맞댐은 목점을 맞추고 어깨 현을 겹친다. 뒤 어깨는 다트를 닫아 꺾여 앞 직선 어깨와 사이에 렌즈형 틈(B=83 에서 3.6cm²)과 어깨끝 단차 0.05cm 가 남는다 —
> 메우지 않고 구성선·면적으로 기록한다(어깨 길이 보정은 패턴선 확정 단계 몫).

## 본문 (한국어 번역본 원문 요지)

- «앞은 **어깨선과 평행으로**, 뒤는 **다트 끝에서 수평으로** 이음선을 넣는다.»
- «앞 몸판은 **AH 다트를 닫아 요크 이음선을 벌리며**, 이때 **늘어난 분량만큼 개더를 더 잡는다**.»
- «뒤 몸판의 개더는 앞 몸판의 개더와 비슷한 정도로 균형을 이루도록 **중심에서** 추가한다.»
- 사진 캡션: 앞에서 보면 박스형, 전체적으로 밑단이 살짝 퍼지는 실루엣. **개더 분량은 뒤는 ∅ 의 0.5배, 앞은 ● 의 약 0.6배.**
- 꼬리말 참조: 개더 분량 비교 P.102 · 천 차이 비교 P.106 · **2곳 이상 맞댄다 P.159** · **닫는다·벌린다 P.161**.
- 도해: 뒤 · 앞(닫기 전, 「닫는다 / 벌린다」 표기) · **맞댄 그림**(앞 요크 + 뒤 요크, «어깨 요크») · **절개 그림**(앞).

## 도해에서 읽히는 것

| 항목 | 읽힌 내용 | 확정도 |
|---|---|---|
| 밑단 옆 | 앞·뒤 모두 **«1»**(Ⓠ·Ⓡ·Ⓢ 와 같은 +1) | 읽힘 |
| **뒤 이음선** | 뒤 다트 끝(apex) 높이의 **수평선**(Ⓠ·Ⓡ 와 같다. Ⓢ 의 BL−5 가 아니다). 요크 중심선(CB)은 원래 위치 그대로 | 읽힘(본문+도해) |
| **뒤 개더** | 중심 쪽 **세로 띠를 몸판에만 평행 추가**(요크는 불변 — 요크 CB 점선이 몸판 CB 보다 안쪽). 띠 폭 = **∅×0.5**. ∅ = **원래 CB 에서 이음선 옆 끝(진동 쪽)까지 이음선 길이 − 2** (도해: ∅ 호가 원래 CB 점선 → 옆끝 2 앞에서 끝남, «2» 표기) | 읽힘(도해 호 끝점). 숫자는 도해 비례 실측뿐 — 구현 때 계산 |
| 뒤 요크 다트 | 뒤 요크에 **어깨 다트(V)가 열려 그려진다**. 「맞댄 그림」에선 «뒤 요크 다트를 맞댄다»(P.159 워크 예시) | 읽힘 |
| **앞 이음선** | **어깨선과 평행**한 사선. 어깨선에서 **«6»** 아래. 시작 = 진동선, 끝 = **목둘레선**(앞중심까지 가지 않는다 — 요크는 어깨를 덮는 띠) | 읽힘 + **확정(김님): «6» = 어깨선에서의 수직거리** |
| 앞 몸판 | 이음선 **아래** 몸판은 CF 까지 이어진다. AH 다트(진동 쪽, 이음선보다 아래)는 **요크가 아니라 몸판에서 닫는다** | 읽힘 |
| **앞 닫는다·벌린다** | BP 에서 **이음선 호길이 1/2점까지 직선 절개**(연직 투영 아님 — 확정, 도해상 진동 쪽으로 약 5° 기욺 · 「벌린다」 선). 진동 쪽 조각을 BP 축으로 돌려 AH 다트(「닫는다」 선)를 닫으면 이음선에 **쐐기**가 벌어진다. 쐐기 폭 = 개더 분량. 절개 그림에서 이음선은 쐐기 위를 **한 선으로 이어** 그려진다(점선 물결 = 개더) | 읽힘(P.161) |
| 앞 «2»·«●» | 앞 이음선 **양 끝(진동 끝·목둘레 끝)에 각각 «2»**, 두 «2» 사이 호가 «●»(개더 구간). 개더는 이음선 양 끝 2cm 를 비운다는 표기로 읽힌다. ⚠ 뒤는 «2» 가 진동 쪽 한 곳뿐 | 읽힘(표기 위치) + **확정(김님): 개더 제외 구간 2cm** |
| 앞 개더 분량 | 본문: **AH 다트를 닫아 벌어진 만큼**(= 쐐기 폭). 캡션의 «●×0.6» 은 그 결과의 **참고 비율**(Ⓣ 의 «5 정도» 와 같은 유형)으로 읽힌다 — 공식이 아니다 | 읽힘(본문). 캡션은 해석 갈림 |
| **맞댄 그림** | 앞 요크와 뒤 요크가 **어깨선에서 맞대어 한 장(«어깨 요크»)**. 뒤 어깨 다트는 닫힌 상태(◎ 에서 내려오는 선). 어깨 맞댐선에 **얇은 렌즈형 틈**이 남는다(앞뒤 어깨 길이 차) | 읽힘 |
| 주름 수·턱 | 도해에 없다 | **미확정(만들지 않는다)** |

## 구현 시 재사용 / 새로 필요한 것 (저장소 확인, 코드 무변경)

- **재사용**: `designYokeSeam.splitSide` 의 뒤 apex-수평 이음선 + `gatherBand`(뒤 띠, 폭만 ∅×0.5 규칙으로 교체) · `designJoin.buttJoin`(순차 맞댐) / `buttSpread` · `designLineTool.splitRingByCut`(순수, 임의 절개선으로 링 분할) · 프리셋 `yokeSeam` 값 확장 패턴("S"·"T")과 `pendingVariant` → `availVariant` 전환.
- **새로 필요**: ① 앞 이음선이 CF/옆선이 아니라 **진동·목둘레 곡선 모서리와 만나는** 분할(현 `cutRing` 은 수평 레벨 + center/side-seam 모서리 전용이라 못 쓴다) ② **BP→이음선 절개 + 진동 쪽 조각 BP 축 회전 + 쐐기 메움**(요크 아래 몸판 한정 — `absorbDart` 와 달리 apex 가 이음선 위가 아님) ③ **앞·뒤 요크 어깨 맞댐 1장** — 새 필드(예: `yoke`)·체크포인트·`designLayout` 가 모두 `frontYoke/backYoke` 쌍을 가정하므로 영향이 크다.
- 최소 변경 예상: `js/designYokeSeam.js`(variant "U"), `js/designBodice.js`(yokeSeam "U" 분기), `js/bodicePresets.js`, `js/bodiceCheckpoint.js`(yokeRow U), 새 테스트 `test/harness/yokeSeamUCheck.js`(결정론: 전 조각 폐곡선·자기교차 0·이음 길이 정합 요크=몸판−개더·뒤 띠 폭 = (이음선−2)×0.5·앞 쐐기 폭 = 각×|BP−T|·면적 보존·밑단 +1·Ⓠ~Ⓣ 바이트 불변). 요크 1장 합치기를 택하면 `designLayout`·`designRenderer`·`bodiceCheckpoint` 의 요크 키 가정까지 넓어진다.
