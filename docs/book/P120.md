# P.120 — 실습 «디자인 변형» 오리지널 디자인 ② (베이식 셔츠) · 앞여밈 단추 [패턴학교]

판독 2026-11-22 (소형 미리보기 + 앞판 확대 크롭 1회). 이 쪽은 **9호 예시 한 벌의 완성 도해**다 — 제도 공식이 아니라 그 디자인의 수치.
구성: 몸판 Ⓒ(P.16) + 소매 Ⓤ(P.51) + 칼라 Ⓜ(P.66). 앞트임 = P.98 ② 앞단 · 소맷부리 트임 = P.91 ④ 덧단. P.169(시접 포함 완성 예)가 이 셔츠다.

## 확정 수치 (도해 글자)
| 항목 | 값 | 비고 |
|---|---|---|
| **단추 크기** | **1.3** (cm) | 도해 가운데 세로 글자 «단추 크기 = 1.3». 지름으로 읽는다 |
| 스티치 폭 | 0.2 · 0.5 | 같은 세로 글자 묶음 |
| 첫 단추 | 앞중심 목점에서 **6.5** | 목점 옆 «1»(목선 1 내림 표시)과 별개 |
| 끝 단추 | 밑단에서 **15** | 밑단 연장 «8» 과 별개 |
| 단추 개수 | 도해상 **6개**, 점선 반원 = 균등 분할 표시 | 개수는 도해 개수(글자 아님) |
| 단추 위치 x | 앞중심선 위 | 원이 앞단 안쪽 세로선(앞중심) 위에 있다 |

## 미확정 (지어내지 않음)
- «2.8» — Codex 판독(2026-11-23): 두 앞단 경계에 연결된 **폭 치수**로 보인다. 단춧구멍 길이의 근거 아님.
- **단춧구멍** — 길이, 중심 대비 시작점/끝점 오프셋 수치는 P.98/120/164~169 에서 **확인되지 않음**(Codex 직접 판독).
- **P.98 ② 앞단(Codex 판독)**: 착용자 **오른쪽**이 단춧구멍 쪽이며 **별도 앞단**, **왼쪽**은 **두 번 접기**.
- **P.169**(같은 셔츠 재단 예): 오른쪽 앞판 옆 별도 앞단에 중심 세로선을 가로지르는 **짧은 가로 표시 6개** — 구멍 방향·배치의 **도해 근거**로 해석(수치 아님).
- **구조 차이**: 현재 앱의 좌우 거울 쌍 컷온 ≠ 교재의 오른쪽 별도 앞단/왼쪽 두 번 접기. 구멍 기하·DXF 는 보류.
- 단추 크기가 이 디자인 전용인지 셔츠 일반 기본인지 — 이 쪽만으로 판단 불가.
