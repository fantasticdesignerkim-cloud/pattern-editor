## 책에서 확정되는 것
- 본문: «Ⓔ 와 같은 방법으로 더 줄인 디자인. 허리에 더 맞추기 위해, **앞은 다트 a + 1cm, 뒤는 다트 e + 1.5cm, 옆선에서 각각 1.5cm 줄인다.** 1개의 이음선에서 줄일 수 있는 분량은 이것이 최대.» 밑단 +1(도해 «1»). 꼬리말 «닫는다…P.160».
- 도입 문장(P.19 상단): 이음선은 «앞뒤 이음선이 어깨선에서 연결되도록 치수를 맞춘다» · «앞 AH 다트와 뒤 어깨 다트는 이동해 이음선에 넣는다».
- 도해: 앞·뒤 각 «앞·옆 / 뒤·옆» 조각 → **최종 4조각**(Ⓔ 와 동일). 앞 어깨→BP 이음선 옆에 «0.5»(Ⓔ 와 동일), 앞 어깨 ● 호(어깨선 재작도)도 Ⓔ 와 동일. 앞 도해 «닫는다» 화살표 = AH 다트(P.160).

## Ⓔ 와 달라지는 것 (그게 전부다)
| | Ⓔ | Ⓕ |
|---|---|---|
| 앞 다트 a 폭 | 1.75 | **1.75 + 1 = 2.75** |
| 뒤 다트 e 폭 | 2.25 | **2.25 + 1.5 = 3.75** |
| 옆선(WL) 줄임 | 1 | **1.5** |
| 밑단 옆 추가 | 1 | 1 |
- 도해 실측으로 «+1»·«+1.5» 가 **다트 폭에 더하는 값**임을 확인: 마름모 폭 화소비 ≈ 앞 2.8cm·뒤 3.7cm(= a+1·e+1.5), 옆선 노치 1.5 ≈ 25px(16px/cm 환산).
- 절개선 시작·경유·끝점 / 닫는 다트(앞 AH만, BP 고정 18.25°) / 회전 조각(옆 조각 BP 위) / 곡선(어깨→BP 최대 0.5cm) / 뒤 어깨 다트 입구 시작 = **전부 Ⓔ 와 같다**(Ⓔ 의 사용자 확정 A안이 그대로 적용).

## 구현 결정 (책 + 잠긴 Ⓔ 결정만으로 단일하게 정해짐 — 새 패턴 원리 선택 없음)
- 몸판 파라미터 = Ⓒ 와 같은 a·e + **옆선 −1.5** + **`waistDartExtraCm:{a:1,e:1.5}`**(신규 엔진 옵션, 배분 뒤 현재 입 폭에 **절대 cm** 를 더함·입 중점 고정·apex 불변) + `princess:"F"`.
- 마름모 확대는 Ⓔ 의 잠긴 규칙(축 둘레 대칭, 앞 축 = BP x / 뒤 = 어깨 다트 끝 x)을 그대로 따른다 — 책이 좌우 몫을 따로 주지 않았으므로 **새로 고른 것이 없다**(총폭만 책 값).
- `designPrincess.split(…, {variant:"F"})` 는 meta 표식만 다르다. 옵션이 없으면(A~Ⓥ·Ⓔ) 새 경로를 호출하지 않는다 → 기존 15종+Ⓔ geometry 바이트 불변.
- 체크포인트: `princessState` 가 파라미터(`princess`·`waistDartExtraCm` = 책 값 {1,1.5} 정확히) · meta(`waistDartExtra` 전/후/증가) · **출력 geometry 의 마름모 폭**을 서로 대조한다. Ⓔ 에 폭 추가가 붙어도·Ⓕ 에서 빠져도 거부(`princess-dart-extra-mismatch`).
