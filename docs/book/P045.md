## 김님 확정 (2026-10-12)

1. 출발 Ⓐ 의 **중심선을 잘라 두 반쪽을 좌우 ∅/2 씩 평행 이동**(회전 없음). 중심 O·SP 는 두 조각으로 갈라지고, **틈 가운데(원래 중심선 위치)가 기준**.
   ● = 손바닥 + 3(손바닥 기본 21, 수정 가능) · ■ = Ⓐ 소맷부리 − ● · **∅ = 0.7● − ■ = 1.7● − W**. B83 기본 ∅ 8.73 — 책 «9 정도»는 예시.
2. 새 소매산 꼭대기를 원래 높이보다 **0.7cm 올림 — 변경 가능한 설정값**. 틈 위를 양쪽 기존 소매산과 자연스럽게 잇는다
   (**틈 주변 필요한 최소 국소 재제도** — 임의 전체 곡선 재설계 금지).
3. **최종 소매산 − AH = 이세 + 개더 총량**으로 표시하고, 출발 Ⓐ 실측 이세와 최종 소매산 증가분(추가 개더)을 **따로** 보인다.
   **상승 0.7cm 와 개더 계수 0.7 은 독립값**(혼동 금지). 이번 개더 계수 = 책 설정 0.7.
4. 소맷부리는 **평행 벌림 후 직선**(책 공정 유지 — 임의 곡선화 금지). 도해의 물결은 개더 표시이지 재단선이 아니다.
5. 커프스 폭 1cm 는 치수 정보만(별도 조각 없음). 표시: 원래 종이 2조각 = 녹색(기본 켜짐·숨김 가능) · 틈/정리 덧댐 = 음영 · 최종선 = 남색 ·
   벌리기 전 비교 도안 = 기본 숨김.

# Ⓚ — «Ⓙ방법 + 절개선을 넣고, 소매산을 기준점으로 잘라서 벌린다» (P.45 하단)

> 2026-10-13 판독 → 같은 날 **김님 마무리 3가지 승인 · 구현 승인**. 화면 검토용 시안(미커밋).
> 판독 사본은 세션 scratchpad 에만 둠(books/ 원본 무수정). Ⓙ 의 «상승 0.7cm» 와 «개더 계수 0.7배» 를 혼동하지 않는다 — **Ⓚ 의 개더 계수는 1.5**.

## 본문·도해(F)

- 본문: «Ⓙ의 방법에 소맷부리 개더 분량을 더 추가한 타입이다. 앞뒤 소매 폭을 각각 2등분해 절개선을 넣는다. 소매 중심선에서 평행으로 잘라서 벌리고,
  절개선에서 소매산을 기준점으로 소맷부리를 잘라서 벌린다. 소맷부리 개더 분량은 커프스 달림 치수의 1.5배.»
- 왼쪽 도해: «□는 Ⓐ의 패턴» — **출발은 Ⓐ**. 절개 3개(중심선 + 앞·뒤 반폭 중점, 반폭 등분 표시), 반폭 절개선은 소매산 쪽 화살표(기준점 = 절개선 × 소매산). 커프스 (손바닥 둘레 + 3) = ●, 폭 1, 나머지 ■.
- 절개 그림: 녹색 4조각. 가운데 틈 = 위아래 같은 폭(평행) «∅/3 (9 정도)», 양옆 틈 = 소매산에서 0 · 소맷부리에서 «∅/3» 쐐기. 꼭대기 «0.7». 소매산 전체·소맷부리에 개더 물결.
- 식: «잘라서 벌리는 분량(∅) = ●×1.5 − ■», ●×1.5 = 개더 분량.
- 캡션: 개더 분량이 많아 Ⓗ~Ⓚ 중 볼륨 최대, 소매산에서 소맷부리로 퍼지는 실루엣.

## 김님 확정 (2026-10-13)

1. 출발 = 같은 몸판·소매길이의 **Ⓐ**(Ⓙ 완료 형상을 다시 자르는 것이 아님).
2. ● = 손바닥 + 3(기본 21, 수정 가능) · ■ = Ⓐ 소맷부리 − ● · **∅ = 1.5● − ■ = 2.5● − W**. 가운데 평행 틈과 양옆 소맷부리 **현 거리 각 ∅/3**(기본 9.31).
3. 가운데 = 두 반쪽을 좌우 **∅/6 평행 이동** → 각 반쪽의 **중심 쪽 조각 고정 · 바깥 조각만** 이동한 «절개선 × 소매산» 기준점에서 회전. O·SP 는 중심 절개로 갈라지고 **틈 이등분선이 기준**.
4. 마무리 ① 소맷부리: 중앙 직선을 고집하지 않고 **전체를 자연스러운 곡선**으로 정리(약간 파임·덧댐 허용).
   ② 소매산: **가운데 틈과 양옆 기준점 꺾임을 각각 최소 국소 재제도.** ③ 소매산 상승 **기본 0.7cm · 수정 가능**(개더 계수와 별개).
5. 산식 소맷부리 60 / 개더 36 은 **최종 곡선 실측과 구분**해 표시. 형상을 산식 길이에 맞추지 않는다.
6. 표시: 원래 종이 4조각 = 녹색(실제 강체 자료 · 기본 켜짐) · 틈 3곳과 소매산 덧댐 = 음영 · 최종선 = 남색 · 벌리기 전 비교 = 기본 숨김. 커프스 폭 1 은 치수 정보만.

## 구현 (시안, `js/designSleeveK.js` · `sleeveKApply.js` · 프리셋 `bunka-sleeve-K`)
