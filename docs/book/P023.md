## 책에서 읽히는 것 (확정)
- 머리말: «목둘레에 턱을 넣어 가슴선 위쪽을 입체적으로 표현한다. 턱은 장식을 위해 천을 접어 꿰맨 주름. 개수·분량·꺾는 방향에 따라 변형 가능. 천 폭이 부족하면 이음선.»
- 본문: «**Ⓘ 와 같이 목둘레에 절개선을 넣어 벌리고, 다시 앞뒤 중심에 턱 분량을 평행으로 추가한다.** 이 분량은 앞 AH 다트를 닫으면서 벌어지는 정도와 같은 분량이 적당.»
- 기준 몸판 = **Ⓘ 와 동일**(제목 «밑단 폭 1cm 추가» = Ⓑ `hemSideOffsetCm:1`, 허리 다트 없음 `waistDartScales` 0). 대상 = **앞·뒤 둘 다**(«※ 뒤로 같은 방법으로 잘라서 벌린다»). 닫는 다트 = 앞 AH(BP) · 뒤 어깨 다트 — Ⓘ 와 같다.
- 연산 = **Ⓘ 의 neckTuck(161) + 중심선 평행 벌림(162)**. P.162: 절개선에 **직각**으로 지정 치수를 끼워 넣는다·«실제로 자르지 않고 베끼며 처리»·마무리 «각지지 않게 완만한 곡선».
- 도해(앞·뒤 모두): 앞중심(뒤중심)선이 바깥으로 **띠 폭 «6»** 만큼 평행 이동 — 띠는 목둘레에서 밑단까지 전 길이(점선으로 CF 이동 전 위치 표시). 띠 위쪽은 목둘레 높이로 수평. 띠 위에서 «박기 끝 2» = 새 CF 에서 목둘레 2cm 아래(대각선 = 턱 접힘 박음선). **«6» 은 앞뒤 둘 다 같은 숫자**.
- 사진 캡션: «턱을 **중심 쪽으로** 꺾으면 음영이 뚜렷해져 입체감이 산다. 턱 분량이 많아 밑단이 약간 퍼지는 실루엣.» (Ⓘ 는 «바깥쪽» — 방향이 반대. 표시 전용.)

## 산식 (책 + 이미 확정된 Ⓘ 규칙으로 읽은 것)
- 목둘레 벌림은 Ⓘ 와 동일 계산: 앞 틈 합 **6.524cm**(θ=18.25°) · 뒤 2.088cm.
- 중심 평행 추가량 **T = 앞 AH 다트를 닫아 벌어지는 목둘레 틈 합 = 6.524cm**, 도해의 «6» 과 일치(반올림 6.5 ≈ 6). 앞·뒤 같은 값(뒤 도해도 «6»; 뒤 자신의 틈은 2.09 라 «6» 과 맞지 않는다).
- 평행 추가 = 중심선(원래 CF 접힘선)에 직각, 목둘레 끝점~밑단 전 길이를 T 만큼 바깥으로. 뒤판 폭·앞판 폭이 각각 T 늘고, 상단은 목둘레 높이 수평, 하단은 밑단 수평으로 닫는다.
