# P.31 — 요크 이음선 ① 변형 Ⓡ «Ⓠ 방법 + 중심에 개더 분량을 추가»

> **출처: [패턴학교]** P.31 (PDF index 30). 판독일 2026-10-01, `books/pages/p031.jpg` 읽기 전용.
> 원본에서 직접 읽히는 것만 적는다. 읽히지 않거나 해석이 갈리는 것은 **미확정**.
> 실행 수치의 단일 진실은 `js/bodicePresets.js` 레코드다. 이 노트는 구현 전 판독 기록일 뿐이다.

## 페이지 머리 문단 (Ⓠ·Ⓡ 공통 — 요크 이음선 ① 라인 설명)

- 요크 = 몸판의 어깨·가슴·등 또는 허리 아래 등을 잘라 천을 이어 맞춘 부분.
- 다트를 활용하거나 천을 이어 몸에 맞게 하는 기능, 그리고 이음선에 개더·플레어·턱 등을 추가해 장식 효과를 낼 수 있다.
- «요크 이음선 ①은 앞바대 같은 가슴 요크의 일종으로, **앞뒤에 모두 같은 모양의 이음선**을 넣는다.»
- «**어깨선에서 앞뒤 요크가 연결되도록 치수를 맞춘다.**»
  → **미확정**: "연결되도록 치수를 맞춘다" 가 (a) 어깨 봉제선 길이 맞춤인지 (b) 어깨에서 앞뒤 요크가 한 장인지
  는 문장만으로 못 가른다. Ⓠ 의 잠긴 결정 #2(별도 조각)를 이 노트가 바꾸지 않는다.

## Ⓡ 본문 (한국어 번역본 원문 요지)

- 제목: **Ⓡ = Ⓠ 방법 + 중심에 개더 분량을 추가.**
- «Ⓠ 의 방법에, 앞뒤 몸판 **중심 쪽에서** 개더 분량을 **평행으로** 추가한다.»
- «뒤의 분량은 **⌀ 의 1배**, 앞도 **⊠ 의 1배**.»
- «개더 분량은 사용하는 천에 따라 적당히 조정한다. 개더는 **턱으로도 변경 가능**.»
- 사진 설명: 앞뒤 중심 부근에 개더를 넣어 앞뒤에서 볼 때는 박시 라인, 옆에서 보면 플레어 실루엣에 가깝다.
- 꼬리말 참조: 개더 분량 차이에 따른 비교 P.102 · 천 차이에 따른 비교 P.106 · 닫는다 P.160.
- 도해 표제: 뒤·앞(다트 닫기 전) + 「패턴 닫는 법」(앞 AH 다트 닫은 상태).

## 도해에서 읽히는 것

| 항목 | 읽힌 내용 | 확정도 |
|---|---|---|
| 개더 분량의 위치 | 앞·뒤 모두 **중심선(CB/CF) 쪽 세로띠**. 중심선에 평행한 점선으로 띠가 표시되고 "개더" 라벨이 붙는다. 띠는 이음선에서 **밑단까지** 이어진다 | 읽힘 |
| 요크 쪽 | 요크 중심선은 원래 중심 그대로(점선 띠가 요크까지 올라가지 않는 것으로 보임) → 늘어나는 건 **몸판(이음선 아래)** | **미확정**(선 겹침으로 단정 불가) |
| 이음선 | Ⓠ 와 같은 수평선(앞뒤 다트 끝 높이). 뒤 이음선 위에 치수 표기 «⌀ · 11 · ⌀» 가 보임 | 읽힘 |
| 분량 기호 | 뒤 ⌀, 앞 ⊠. 같은 기호는 같은 길이. 뒤: 띠 폭 위(CB 바깥쪽 호)와 이음선 아래(CB→«11» 끝보다 1cm 짧은 지점) 두 곳에 ⌀. 앞 패턴 닫기: 이음선 위 ⊠ 두 호 — (apex 쪽 점→원래 CF) 와 (원래 CF→추가된 CF) | 읽힘 |
| **뒤 ⌀ 의 정의** | **⌀ = 10cm — 김님 확정(잠긴 도메인 판단, 2026-10-01).** 뒷목중심점(BNP)과 뒷중심 가슴라인점(CB 의 BL) 사이 **1/2 높이에서 수평으로 11cm** 간 점을 잡고 **1cm 를 빼서** 10cm. 도해의 «11» 과 «1» 이 이 계산이다(11 − 1 = 10). **다트 입 폭도 흡수 길이도 아니다.** 앞 노트(초판)의 두 선택지는 둘 다 틀렸다 | **확정(사용자)** |
| 뒤 개더 띠 폭 | 뒤 몸판은 CB 에서 **⌀ = 10cm** 바깥으로 평행 추가(본문 «⌀ 의 1배»). 도해에서 띠 폭 호 ⌀ 와 이음선 아래 ⌀ 가 같은 기호 | 확정 |
| **앞 ⊠ 의 정의** | **⊠ = 앞중심에서 AH 다트 끝점까지 이음선상 수평거리 − 1cm — 김님 확정(잠긴 도메인 판단, 2026-10-01).** 뒤의 11−1 과 같은 구조. 앞 개더 띠 폭 = ⊠ ×1 | **확정(사용자)** |
| 앞 ⊠ 의 값 | 책에 숫자는 없다. 우리 geometry(B=83, W=64, BL=38)에서 앞중심→다트 끝 수평거리 8.9875 − 1 = **7.9875cm**(구현에서 계산, 하드코딩 아님). 뒤는 10cm 고정 | 계산값 |
| 밑단 | 앞·뒤 옆 밑단 «1» 표기 — Ⓠ 와 동일(밑단 옆 +1) | 읽힘 |
| 「11」·이음선 끝 «1» | Ⓠ 에서는 «쓰지 않음» 으로 잠겼다(이음선 높이는 apex y). Ⓡ 에서 이 표기는 **⌀ 를 정하는 계산(11−1=10)** 으로만 쓰인다 — 이음선 위치를 바꾸는 값이 아니다. Ⓠ 잠금은 그대로 | 읽힘/Ⓠ 유지 |
| 김님 설명의 «1/2 높이» ↔ Ⓠ 의 «apex y» | 김님은 11cm 점을 BNP–CB 가슴라인점의 1/2 높이에 둔다고 했다. Ⓠ 이음선은 다트 apex y 이다. 두 높이가 같은지는 구현 때 수치로 대조해야 한다(이 노트는 단정하지 않는다) | **구현 전 수치 대조 항목** |
| 다트 | 앞 AH 다트는 「닫는다(P.160)」 로 이음선에 흡수. 뒤 어깨 다트도 닫는다 | 읽힘(Ⓠ 와 동일) |
| 개더 주름 모양·턱 | 주름 위치·개수·턱 치수는 도해에 없다 | **미확정(책에 없음)** |

## Ⓠ ↔ Ⓡ 차이 (원본 근거 기준)

- **같은 것**: 이음선 위치(다트 끝 높이 수평), 다트 흡수, 밑단 옆 +1, 앞뒤 별개 패턴(Ⓠ 잠금 유지).
- **다른 것(유일)**: Ⓡ 는 **몸판 중심쪽에 세로 띠(개더 분량)를 평행 추가**한다. 분량 = 뒤 ⌀×1, 앞 ⊠×1.
  요크·이음선 높이는 변하지 않는다. 결과 이음선 아래 몸판이 중심 쪽으로 그만큼 넓고, 요크에 개더로 이어진다.
- 천에 따라 분량 조정 가능, 턱 대체 가능 — **옵션 기록이며 기본 수치 없음.**

4. 앞 중심 쪽 추가 시 앞 여밈(센터) 선 처리
