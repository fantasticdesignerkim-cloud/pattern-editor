## ★ 정정: Ⓗ 는 P.162(평행)가 아니라 P.163(기준점 고정 부채꼴)이다
- P.21 꼬리말이 가리키는 연산: **닫는다·벌린다 P.161 · 기준점을 잡고 잘라서 벌린다 P.163** (그리고 비교용 P.104·P.107).
  **P.162 는 인용되지 않는다.** 도해(절개 그림)도 평행 띠가 아니라 **진동 가장 안쪽 점에서 퍼지는 부채꼴**이다.
- 그래서 `bodicePresets.js` 의 Ⓗ `blockedBy`(«162 평행 절개가 없다 · P.21 미판독»)는 **틀린 사유**다 — 정정 대상.
  (구현 승인 시 같이 고친다. 이번 커밋은 docs 만이라 코드는 건드리지 않았다.)

## 책에서 읽히는 것 (확정)
- 본문: «Ⓖ 의 방법에, **진동 둘레 가장 안쪽을 기준점으로 수직의 절개선**을 넣고 플레어 분량을 넣는다. 이 분량은 다트를 닫으면서
  벌어지는 분량과 같은 분량까지가 **최대**. 플레어 분량은 **잘라서 벌리기 전 가슴둘레 치수의 1배**.»
- 절개 수: **앞 1 + 뒤 1** (Ⓖ 의 apex→밑단 절개는 그대로 있고, 그 옆에 진동 가장 안쪽→밑단 수직 절개가 하나 더). 뒤: «앞과 같은 방법으로 계산해 잘라서 벌린다».
- 산식(도해): **∅ = ●×1 − (3 + ■)** — ∅ = 잘라서 벌리는 분량(밑단), ● = 가슴둘레 치수(도해에서 가슴선을 따라 CF~옆선 호로 표시), 3 = 밑단 옆 추가(Ⓖ 와 동일), ■ = 앞 AH 다트를 닫으며 벌어지는 밑단 분량(Ⓖ 의 `flareCm.spread`).
  즉 밑단 총 추가분 3 + ■ + ∅ = ●.
- 몸판 = Ⓖ 와 같다: 허리 다트 없음(`waistDartScales` 전부 0) · 밑단 +3 · 앞 AH / 뒤 어깨 다트 닫음 · CF 고정.
- 어깨 주위는 플레어를 넣지 않는다(사진 설명). 처리한 곳(밑단)은 **완만한 곡선**(P.157 공통 불변식) — 우리 `fairBridge` 규약.

## 엔진 재사용 판정
- **엔진을 새로 만들 필요는 없어 보인다**: Ⓖ(`designFlare.closeDartSpread`) 결과 한 조각을 진동 기준점에서 밑단까지 수직선으로 가르고,
  `designJoin.buttSpread`(기준점 고정 · 밑단 chord 지정 · fairing — Ⓝ·Ⓞ·Ⓟ 가 쓰는 P.163)로 다시 한 장으로 맞대 벌리면 된다.
  앞·뒤 모두 «한 조각 → 둘로 갈라 → 기준점 고정 벌림 → 한 조각» 이라 `bodyParams` 에 새 옵션 하나(예: `flare.cut`)로 연결 가능.
  **다만 이 조합(Ⓖ 출력 위 절개)은 아직 한 번도 돌려 보지 않았다 — 구현 때 실측 확인 항목.**
- 기존 실행 가능 프리셋 geometry 는 옵션이 없으면 새 경로를 호출하지 않으므로 바이트 불변으로 둘 수 있다(Ⓕ·Ⓥ 와 같은 방식).

## 확정 결정 (사용자 A안, 2026-10-03)
- **∅ = min(●×1 − (3 + ■), ■)** — 교재 «■ 까지가 최대» 가 산식보다 우선한다. 앞 ∅ 9.590(clamp 없음) · 뒤 ∅ 9.915(산식 10.138 → ■ 로 clamp).
  «3» 은 `hemSideOffsetCm` 값이다(Ⓗ 레코드 3). 산식 ≤ 0 이면 거부(`slash-not-positive`).
- **엔진**: 새 엔진 없음. `designFlare.closeDartSpread`(Ⓖ) → `designFlare.slashSpread`(접착 코드: 절개 분할·`designJoin.buttSpread` 호출) — 밑단은 기존 `fairBridge` 접선 연속 이음(길이 보존).
  `closeDartSpread` 는 스칼라(`rotationRad`·`mouth`·`mouthEdges`)만 더 돌려주고 geometry 는 그대로(Ⓐ~Ⓥ 17종 sha 불변).
- **절개 방향** = 원본 수직선이 Ⓖ 회전으로 놓인 방향(`R(rotationRad)·(0,1)`). 고정 = 중심 조각(Ⓖ 규약) · 회전 = 옆선 조각, 기준점 둘레 chord ∅.

- 플레어 후 수평 계측은 무효(Ⓖ 와 동일, UI 가 이유를 말한다).
