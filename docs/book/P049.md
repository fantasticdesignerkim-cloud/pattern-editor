## 미확정(김님 확인 필요)

- 몸판 진동의 **옆선 쪽 끝 방향**(시안 = 시작 접선의 현 대칭 — 관례).
- 기본 몸판 진동 핸들 **0.4**(관례) — **1/3 이면 앞판에서 두 곡선이 새 SP 에서만 닿고 교차하지 않아** 규칙(가)가 정의되지 않는다(거부, 이세 0 으로 대체하지 않음). 도해는 위쪽이 거의 겹쳐 그려져 있다.
- 소맷부리 교점 곡선(시안) — 팔꿈치 둘레 ≥ 32.5(● ≥ 36.5 ≈ 소매 반폭) 또는 소맷부리 아래 0 이면 두 직각선이 앞쪽에서 만나지 않아 거부(`cuff-corner-conflict`). 이때 직각 조건 중 무엇을 풀지 미정. 뒤 처리 쐐기(벌린 다트)는 새 진동 안쪽이라 형상에 영향 없음 — 별도 표시 안 함.
- 몸판 진동 핸들 0.4 · 교차점 방식은 **현재 시안 설정**이다 — 책의 확정 규칙으로 기록하지 않는다(Codex 검토 2026-10-28).

## 소맷부리 S 굽이 보완(2026-10-28)

- **원인**: 반쪽마다 E 접선(중심선 직각)·C 접선(밑선 직각)을 대칭 핸들 현×1/3 로 이었다. C(= P + 1.5 밑선 연장)는 밑선이 중심 쪽으로 좁아져
  기준선 E→P 거의 바로 아래에 있어 현이 E 접선과 3° 밖에 안 벌어지는데, C 접선은 28° 꺾인다 → 대칭 핸들은 앞쪽을 반대로 휘었다 되돌아와
  반쪽마다 변곡(뒤 t≈0.28 · 앞 0.72). 중심 접속(G1 ≈ 5e-14°)은 원인이 아니다.
- **도해와 대조**: 굵은 소맷부리는 E 에서 기준선을 따라가다 C 근처에서 꺾여 C(∟)로 들어간다 — 굽이는 C 쪽 하나.
- **보완**: 같은 두 끝 직각선의 교점 I(기준선 E→P 위 뒤 22.78 · 앞 22.81)를 모서리로 한 곡선(제어점 E+⅔(I−E) · C+⅔(I−C)).
  E·P·C·U·소매산·밑선·몸판 무변경. 현에서 몸 쪽 파임 1.68 → 0.60. 끝 각 90° · 중심 G1 그대로. 소맷부리 51.32 → 50.79 · 실제 개더 25.32 → 24.79.
- 대칭 1/3 핸들·파임 허용량·«S 금지» 같은 일반 규칙은 만들지 않았다 — 교점이 두 끝 앞에 없으면 거부(사유)만 한다.

## Ⓢ — «Ⓡ 방법 + 소매 중심에 개더 분량을 추가한다»(P.49 하단)
