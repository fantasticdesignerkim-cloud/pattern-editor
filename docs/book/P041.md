## Ⓑ 판독 (확정)

- 출발 = **Ⓐ 의 패턴**(도해 흰 박스). «소매 폭의 비율로 소맷부리 치수를 결정하고, **앞뒤 소매 폭을 각각 2등분**해, 소매 폭과의 차이를 소맷부리에서 자른다.»
- **소맷부리 치수 = 소매 폭 × 3/4** (기준). 단 **손바닥 둘레 + 3cm(여유분) 이상**이 되도록 한다.

- 결과 모양: «소맷부리를 향해 좁아지는 직선적이고 세련된 소매» — 소매산 곡선·결 방향 중심선은 Ⓐ 그대로.

## 강체 회전의 귀결과 fairing (2026-10-06 — 책 공통 주석 «처리한 곳이 각지지 않게 완만한 곡선으로»)

강체 닫힘의 귀결(관찰값): 바깥 소맷부리 모서리 ≈0.5cm·아랫점 ≈0.7cm 아래로, 소매산 P 에 회전각(≈5°) 꺾임, 쐐기 변 끝에 R(secθ−1) ≈ 0.17cm 단차(`hem-step-*`). 앞·뒤 소매산 길이·이세, 밑선 길이(38.352)는 회전 불변.
반환 outline 은 이를 정리한 **한 조각**(`[소매산 path, side-seam-front, hem path, side-seam-back]`, `hem-step-*` 없음)이다.

- **소매산**: 각 P 주변 [P−ℓ, P+ℓ](호 길이)만 **끝점·접선 고정 Hermite cubic 한 개**로 교체(경계 G1). 핸들 스칼라를 이분법으로 풀어 교체 구간의 호 길이를 보존 → 앞·뒤 소매산 길이·이세 불변(drift < 1e-6cm). ℓ = min(2.0, 인접 호의 40%).
- **소맷부리**: (0,hemY)에서 수평 접선인 **자연 Hermite**(핸들 = 각 반쪽 chord/3) 두 개, 바깥 끝 = 회전된 모서리·접선 = 회전된 변 방향. y 단조·변곡 없음. 호 길이는 W×3/4 대비 **절대오차 ≤ 1e-3cm** 로 검증한다 — 강체 닫힘의 호 길이 예산이 직선거리와 거의 같아(여유 −0.0013~+0.005cm) 길이를 exact 로 맞추는 해가 없는 경우가 있다(1344 sweep 에서 66변). 실측 최대 5.1e-4cm.
- 고정: SP · 결 중심선 · (0,hemY) · 회전된 겨드랑/커프 모서리 · 옆선 길이(비트 동일).

**★ 아래 수치는 모두 책의 설계 수치가 아니라 구현 관례·검증 공차다**(승인된 입력 sweep 1344건 = AH 5×5 · 어깨높이 3×3 · 소매 42~66cm 6종 에서 실측해 확정):

| 값 | 용도 | 실측 |
|---|---|---|

| 소매산 편차 ≤ 0.1cm | 게이트(강체 닫힘 대비) | 최대 0.0149 |
| **소맷부리 편차 ≤ 0.46cm** | **품질 회귀 한계**(전용 테스트가 검증, 모듈 게이트 아님) | **최대 0.4535**(42cm) · 0.3905(48) · 0.3574(52) · 0.336(55) · 0.3055(60) · 0.2755(66) |

### 김님 확정 공정 (2026-10-08, 종이 작업 기준)

1. **종이 조각의 강체 이동**이다 — 늘림·휘기·좌표 억지 조정·소매산 fairing 으로 길이만 맞추는 우회 불가.
2. **소매중심선을 포함한 중앙 조각이 고정**이고 양옆 조각이 움직인다.
3. **왼쪽(도해 뒤쪽)은 EL 까지 맞대고**, EL 아래는 **자연스럽게 벌어지게** 둔다(뒤 열린 V).
4. **오른쪽(도해 앞쪽)은 보이는 EL 가로선에서 실제로 절개**해 하부 조각이 움직일 수 있게 한다. 그러면 겹치는 부분이 생긴다.
5. **겹친 길이만큼 소매구 쪽을 늘려서(연장) 앞·뒤 옆선 길이를 맞춘다.** 종이 조각 자체를 늘리는 것이 아니라 소매구 끝 연장이다.
6. **앞 중앙 경계 선택 규칙**: EL 지점에서 두 굵은선 중 **소매중심선에 가까운 선**이 중앙 조각 경계이고, **교차점 너머에서도 그 같은 선을 따라간다**(항상 왼쪽 선이라는 뜻이 아니다).
7. 각 ‘1’ = 1cm · 같은 ⊠ = 같은 겹침량.
8. **소매산 (2026-10-08 최신 확정, 이전 «최종 Ⓐ 윤곽 완전 고정» 기록을 대체)**: Ⓐ 는 **출발 소매산**이다. 맞댐 뒤 조각 이동으로 소매산이 **조금 찌그러지는 것은 정상**이고,
   **그 맞댐 결과를 자연스럽게 이어 다시 그린다.** 원래 Ⓐ 를 그대로 복사하는 것도, 길이만 맞추려고 임의로 변형하는 것도 아니다. 김님 원문: «소매산은 조금 찌그러질 거야, 자연스럽게 이어지도록 다시 그려야지».
   → 소매산 재제도의 성격(목적·보존·검증 항목)은 아래 «소매산 재제도» 절. **Ⓐ 와 길이 exact 동일을 새로 가정하지 않는다.**

### 방법 교훈 (패턴 «맞댄다» 계열 작업의 순서)

① Ⓐ 원형 위에 **완성 가정선**을 먼저 그린다 → ② **원형선 / 가정선 / 절개선**을 구분한다 → ③ 같은 ◎ / 채운 ●◎ 의 **맞댐 대응과 순서**를 확인한다 →
