## Ⓑ 판독 (확정)

- 출발 = **Ⓐ 의 패턴**(도해 흰 박스). «소매 폭의 비율로 소맷부리 치수를 결정하고, **앞뒤 소매 폭을 각각 2등분**해, 소매 폭과의 차이를 소맷부리에서 자른다.»
- **소맷부리 치수 = 소매 폭 × 3/4** (기준). 단 **손바닥 둘레 + 3cm(여유분) 이상**이 되도록 한다.
- 맞댄 그림: **소매 폭 − 소맷부리 치수 = ●**, 절개 2곳(앞·뒤 각 반폭의 중간)에서 **● /2 씩** 소맷부리에서 맞댄다(도해의 «●/2» 두 개). 맞대는 방식은 «맞댄다»(P.157).
- 결과 모양: «소맷부리를 향해 좁아지는 직선적이고 세련된 소매» — 소매산 곡선·결 방향 중심선은 Ⓐ 그대로.

## 강체 회전의 귀결과 fairing (2026-10-06 — 책 공통 주석 «처리한 곳이 각지지 않게 완만한 곡선으로»)

강체 닫힘의 귀결(관찰값): 바깥 소맷부리 모서리 ≈0.5cm·아랫점 ≈0.7cm 아래로, 소매산 P 에 회전각(≈5°) 꺾임, 쐐기 변 끝에 R(secθ−1) ≈ 0.17cm 단차(`hem-step-*`). 앞·뒤 소매산 길이·이세, 밑선 길이(38.352)는 회전 불변.
반환 outline 은 이를 정리한 **한 조각**(`[소매산 path, side-seam-front, hem path, side-seam-back]`, `hem-step-*` 없음)이다.

- **소매산**: 각 P 주변 [P−ℓ, P+ℓ](호 길이)만 **끝점·접선 고정 Hermite cubic 한 개**로 교체(경계 G1). 핸들 스칼라를 이분법으로 풀어 교체 구간의 호 길이를 보존 → 앞·뒤 소매산 길이·이세 불변(drift < 1e-6cm). ℓ = min(2.0, 인접 호의 40%).
- **소맷부리**: (0,hemY)에서 수평 접선인 **자연 Hermite**(핸들 = 각 반쪽 chord/3) 두 개, 바깥 끝 = 회전된 모서리·접선 = 회전된 변 방향. y 단조·변곡 없음. 호 길이는 W×3/4 대비 **절대오차 ≤ 1e-3cm** 로 검증한다 — 강체 닫힘의 호 길이 예산이 직선거리와 거의 같아(여유 −0.0013~+0.005cm) 길이를 exact 로 맞추는 해가 없는 경우가 있다(1344 sweep 에서 66변). 실측 최대 5.1e-4cm.
- 고정: SP · 결 중심선 · (0,hemY) · 회전된 겨드랑/커프 모서리 · 옆선 길이(비트 동일).

**★ 아래 수치는 모두 책의 설계 수치가 아니라 구현 관례·검증 공차다**(승인된 입력 sweep 1344건 = AH 5×5 · 어깨높이 3×3 · 소매 42~66cm 6종 에서 실측해 확정):

| 값 | 용도 | 실측 |
|---|---|---|
| ℓ ≤ 2.0cm · 인접 호 40% | 소매산 교체 구간 | 최소 ℓ = 2.0 |
| 소매산 편차 ≤ 0.1cm | 게이트(강체 닫힘 대비) | 최대 0.0149 |
| **소맷부리 편차 ≤ 0.46cm** | **품질 회귀 한계**(전용 테스트가 검증, 모듈 게이트 아님) | **최대 0.4535**(42cm) · 0.3905(48) · 0.3574(52) · 0.336(55) · 0.3055(60) · 0.2755(66) |
| \|κ\| < 0.03/cm 평탄 구간은 변곡으로 세지 않음 | **테스트·게이트용 수치 공차** | 무시 구간 최대 피크 0.0124 vs 실제 곡률 구간 최소 0.1345 |
| 소맷부리 합 오차 ≤ 1e-3cm | 완료 기준 | 최대 5.1e-4 |

0.46 은 현재 입력 범위의 실측 최댓값(0.4535)에 둔 여유이므로 **입력 범위를 넓히거나 규칙을 바꾸면 다시 실측**한다. 소맷부리 편차는 짧은 소매일수록 커진다(회전각이 커서). 강체 폴리라인 대비 편차는 게이트가 아니라 품질 측정치(`meta.fairing.cuff.*.deviationCm`).

## Ⓒ (같은 쪽 하단 — 엔진 코어 구현·검증, 2026-10-07)

«소맷부리 치수를 결정하고, 인체 곡선을 고려해 그린 뒤 맞댄다». 완성된 모양을 가정해 그린 뒤 **1장의 소매**로 만든다. **뒤쪽에 소맷부리 다트**(EL 팔꿈치선에서 아래로 점점 좁아지는 팔 모양).

**시도 이력(기록)**: ① 1차 구현 — 바깥 구간 편차·다리 길이차를 허용해 반려 ② 사양 충돌(●:2●:● ↔ 앞 겹침 1cm 고정) 보류 ③ 앞 EL 쐐기 보류 ④ **이번 재개 — 쐐기는 회전 중심을 EL 점으로 잡은 데서 생긴 것이었고 중심을 앞 절개축 위 끝으로 바로잡아 해소**. 미해결 3회 후 해결.

**★ 사용자 확정(2026-10-07, 누적)**: ●:2●:● = 1:2:1 **우선** · 앞 겹침 «정확히 1cm» **철회, 겹침량은 치수별 계산**(B83 소맷부리 변 따라 1.487) · EL 기본 31.4(수정 가능) · EL 위 절개축 = 앞·뒤 반폭 중점 · EL 아래는 1:2:1 경계점으로 꺾음 · 앞 처리 후 뒤 다트 역산 · 최종 열린 뒤 다트(EL 꼭짓점~소맷부리) · **앞 EL 절개는 겹치는 것이다 — 열린 앞 다트·종이 보충이 아니다**.

**P.41 하단 도해 판독(읽기만, books/ 무변경)**: 앞 절개 두 선이 소매산 교점에서 시작해 EL 에서 약 1 벌어졌다가 아래에서 교차·겹침(도해 ⊠ «(겹친다)» — EL 선 쪽 쐐기와 소맷부리 모서리 쪽 쐐기가 같은 크기 ⊠ 로 표기). 뒤는 EL 에서 소맷부리로 열린 V 노치 + 소맷부리 ●(뒤 바깥) 구간. 도해는 개략도라 수치는 읽지 않고 김님 확정 사양과 아래 수학으로 구현했다.

**조각 변환(수치 확인)**: 소맷부리선이 경계점 C 를 지나고 앞 구간이 정확히 ● 가 되는 **강체** 회전은 중심이 앞 절개축(x = aF) 위에 있을 때만 성립한다 — 중심~소맷부리선 거리 D, 중심~C = √(D²+(aF−●)²) 이므로 피타고라스로 A'C = aF−● = Of−●, 앞 구간 \|F'C\| = ● 가 **항등식**(회전각 γ = 2·atan((aF−●)/D)). 그러나 중심을 **EL 점**으로 잡으면(이전 모델) EL 선에 쐐기가 열린다(B83 8.26°·틈 1.08cm·4.04cm²) — 겹침량을 계산으로 바꿔도 사라지지 않았던 이유다. 쐐기가 없으려면 앞 바깥 조각이 **절개축 위 끝에서 소맷부리까지 한 덩어리**로 돌아야 한다(Ⓑ 의 소매산 교점 회전과 같은 구조):
```
 전(Ⓐ)                      후(Ⓒ)
  cap ─P_f─ cap              cap ─P_f╲─ cap (앞 소매산 P_f 아래쪽만 γ 회전, 꺾임 γ)
       │ ▏                        ╲╲  ← 겹침 렌즈: 꼭짓점 P_f, EL 에서 1.65, 소맷부리에서 1.48(소맷부리 변 따라 1.487)
  ─────EL────── 옆선              ─EL──╲── 옆선(직선, 길이 불변)
       │ ▏                            ╲╲
  ─────hem─────              ───────C──F'  (회전한 소맷부리선이 C 를 지남, |F'C| = ●)
```
- 앞 회전 중심 = 앞 절개축 위 끝(소매산 교점 P_f), γ = 2·atan((aF−●)/D) = **3.68°**(D = 소매길이−P_f.y = 46.3). 절개축 전체가 겹침 렌즈 — **EL 선에 쐐기·틈 없음**(렌즈 최소 폭 −9e-16, EL 에서 1.653cm, 소맷부리 쪽 1.484cm). 옆선은 한 직선·길이 불변(재작도 없음), 종이를 더하지 않는다(합집합 격자 대조 불일치 0).
- **소매산(raw → 최종)**: raw 강체 결과는 앞 소매산을 P_f 에서 쪼개 아랫점쪽만 회전한 것(길이·ease 불변, P_f 에 γ 꺾임)이고 **meta.rigid 에 감사용으로만** 남는다. 김님 승인(2026-10-07)으로 P_f 주변 [P_f−ℓ, P_f+ℓ](ℓ=2cm) 만 끝점·접선 고정 Hermite 한 개로 정리해 꺾임을 없앴다 — 아랫점·뒤 소매산·SP 는 그대로이고 «소매산 비트 동일» 요구는 이 P_f 구간에 한해 대체(길이·이세 보존은 유지). **아래 «곡선 정리» 참고.**
- 뒤: 뒤 구간 = ● → 뒤 바깥 조각은 Ⓐ 자리(회전 없음), 안쪽 변만 E_b→D(뒤 모서리에서 ●). 바깥 변 Ob = \|aB\| 라 중앙 변 좁아짐 = 덜어냄(2.521) → 다트는 절개축 대칭, **두 다리 길이가 항등식으로 같다**(B83 20.7537, 차 0). 폭 5.043cm, 꼭짓점각 13.96°, 다리 2 를 돌려 다리 1 에 얹으면 끝점 편차 1e-14.
- 윤곽 = **합집합 경계**(겹침 내부 경계 = 회전한 절개변·중앙 조각 앞 변은 윤곽에 없고 construction 에만). 다트 두 다리는 윤곽에 연속으로 남는다.

- **호 길이 보정**: 볼록 곡선은 두 직선 합보다 반드시 짧아 정리만 하면 소맷부리 구간이 줄어든다(공차로 덮지 않음). raw 의 두 자유도 — **앞 회전각 γ'**(B83 3.6768° vs raw 3.6785°, Δ −0.0017°)·**뒤 다트 가상 모서리 x**(raw −6.012 → 이동 ≈0.12cm, 다리 각 미세 변화) — 를 보정해 최종 곡선의 뒤 바깥 = ●, 앞 모서리~다트 모서리 = 3● 를 정확히 맞춘다(잔차 < 1e-11). 앞 경계점은 앞 모서리에서 호 길이 ● 인 점(raw C_f 에서 B83 0.032cm), 중앙/뒤 경계는 새 다트 모서리 C_b'(raw 에서 0.121cm). 열린 다트 폭 5.052(raw 5.043)·두 다리 길이 같음(차 1e-14)·닫힘 정합 1e-14 유지.
- **소매산 길이·이세**: 앞 소매산 21.471359 = 원본(차 1.8e-11), 뒤 22.852854 불변. 이세는 최종 곡선 GL 실측(총 2.111913, 뒤 1.267654, 앞 0.844259)이 권위값 — Ⓐ 기록(2.111889)과는 2.4e-5 차이로 Ⓐ 쪽 표본 길이 측정 오차 수준이라 `easeSourceA` 로 분리 보존.
- **수치 오차 vs 형상 편차(공차 근거)**: 수치 오차(호 길이·G1·다리·길이 보존) 공차 **1e-9** — sweep 최대 4e-11. 형상 편차(raw 강체 결과 대비 Hausdorff, 곡선 정리의 본질적 결과이므로 공차가 아니라 **품질 가드**): 소매산 최대 0.0155(가드 0.05) · 소맷부리 앞/중앙 0.079 · 다트 모서리 0.360(가드 0.5, 꼭짓점각 44.8° 까지 포함) · 경계점 이동 앞 0.079·뒤 0.371 · 앞 회전 보정 0.0002°. 구간 길이를 이 가드로 풀지 않는다. 이세 대 Ⓐ 기록 한계 5e-5 는 Ⓐ 측정 오차 수준(관측 3.2e-5).
- **정리하지 않은 것(의도된 모서리)**: 소매산 끝(아랫점)·앞 모서리·다트 노치 꼭짓점·다트 모서리(⟂)·뒤 모서리.
- **내부 경계**: 겹침 내부 경계(회전한 절개변·중앙 조각 앞 변)는 최종 outline 에 없다(construction 에만). 독립 합집합 대조는 raw 윤곽 기준이라 최대 정리 편차+0.05cm 띠 밖에서 비교한다(sweep 격자 19.9만점 불일치 0).
