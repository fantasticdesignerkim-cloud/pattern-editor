## 책에서 읽히는 것 (확정)
- 머리말: 개더로 가슴선 위쪽을 입체적으로 표현. 개더 분량 표준 = 두꺼운 천 0.7~1배 · 얇은 천 1~2배 · 어깨 가까이까지 개더를 넣으면 들뜨기 쉽다 · 천 폭이 부족하면 이음선(표시·주의 문구, geometry 아님).
- 제목: «Ⓚ 방법 + 중심에 개더 분량을 추가». «Ⓚ와 같은 방법으로 다트를 닫아 목둘레를 벌리고, **다시 앞뒤 중심에 개더 분량을 평행으로 추가**한다. 개더 분량은 뒤는 ∅의 1.5배, 앞은 ●의 2배.»
- 기준 몸판 = Ⓑ(밑단 «1»), 허리 다트 없음(Ⓚ 와 같다). 대상 = 앞·뒤 둘 다. 절개 = 앞·뒤 각 1개, 위치 앞 «4»·뒤 «3»(Ⓚ 와 같다). 닫는 다트 = 앞 AH · 뒤 어깨 다트 전부.
- **절개 그림의 산식: «앞 중심에서 추가하는 분량(☒) = ●×2 − ■»**, «※ 파도선은 개더 분량», «뒤도 배율은 다르지만 같은 방법으로 계산해 잘라서 벌린다».
- 도해: 중심선을 평행하게 옮긴 띠(밑단까지), 띠 폭에 «☒(7 정도)»(앞)·«5 정도»(뒤) 표기. 띠 윗변은 목둘레 높이로 수평(Ⓙ 와 같은 띠 구조).

## ✅ 사용자 확정 (2026-10-04, 질문 1건)
**■ = 해당 쐐기의 틈**(절개 그림 쐐기 입구 기호) → **☒ = 총 개더 분량 − 쐐기 틈 = (ratio − 1)·틈 현.**
앞 ●×2 − ● = ● = 6.752cm(도해 «7 정도» 와 산식·실측 일치) · 뒤 ∅×1.5 − ∅ = 0.5∅ = 1.005cm. **총 개더 분량 보존이 우선**.

## ⚠ 미해결 개략 표기 (확정 수치로 쓰지 않는다)
뒤 도해의 **«5 정도»** 는 이 산식·총 개더 분량과 양립하지 않는다(∅=2.009 에서 1.5∅=3.014 가 상한이라 5cm 가 나올 수 없다). 도해의 개략 표기로 보고 **띠 폭에 쓰지 않았다**. 회귀 테스트가 «뒤 폭을 5 로 정하지 않았다»·«뒤 띠 폭 변조(5) 거부» 로 고정한다. 책의 뒤 도해가 다른 ∅(다른 치수·다른 읽기)를 쓴 것일 수 있으나 확인 수단이 없다.

## 산식·실측 (B83·W64)
- 절개 1곳이 θ 전부를 벌린다(앞 18.25° · 뒤 11.38°) — **Ⓚ 와 완전히 같은 절개·틈**(●=6.752 · ∅=2.009cm).
- 띠 폭 ☒: 앞 **6.752** · 뒤 **1.005**cm. 새 중심선 = 원래 중심선에서 직각 ☒, 윗·아랫변은 edge 없는 선(길이 ☒, 중심선에 직각).
- 총 개더 분량(줄이는 길이): 앞 ●×2 = **13.504** · 뒤 ∅×1.5 = **3.014** = 쐐기 틈 + 띠 폭.
- 개더 구간 = 절개 지점(SNP 쪽 다리 끝)부터 **새 중심(띠 윗변 포함)** 까지, SNP 쪽 앞 4 · 뒤 3cm 제외(Ⓚ 와 같은 사용자 확정 B안의 연장). 앞 20.634 → 7.130 · 뒤 7.707 → 4.693.
- **봉제 목둘레 = 원래 목둘레 호 합**: 앞 11.130 · 뒤 7.693cm (Ⓚ 뒤는 8.698). 총 분량을 개더로 전부 소화하므로 목둘레가 원래로 돌아온다.
