# P.80 — 숄 칼라 j · "3cm의 칼라 허리"

> 판독 완료(수치) · 제도 절차는 [P154.md](P154.md).

## 10교시 머리말(P.81 상단, 그대로)

> 목에 숄을 걸치는 듯한 디자인으로 둥근 칼라. 위 칼라와 라펠로 구성되어 있지만 **깃아귀가 없고**,
> 일명 수세미 칼라라고도 부른다. 칼라를 꺾었을 때 이음선이 보이지 않도록 **안단은 겉 라펠과
> 겉 위 칼라까지 이어서 재단한다.** 칼라 허리의 높이나 칼라 폭, 누임 치수에 따라 느낌이 달라진다.
> **여기서는 칼라 폭은 일정하게 두고 칼라 허리의 높이를 변경한 2종류를 소개한다.**

★ 테일러드(h·i)는 "칼라 허리 **와 누임 치수**를 변경한 2종류", 숄(j·k)은 "**칼라 허리의 높이**를
변경한 2종류"라고 쓴다. 실제 수치는 둘 다 허리·누임이 함께 움직인다(k 본문이 그 이유를 밝힌다).

## 본문(그대로)

> 숄 칼라의 기본형. **몸판의 목둘레, 라펠, 위 칼라의 순으로 제도한다.**
> 꺾임 끝은 **BL과 WL 사이를 2등분한 위치**로, 칼라 폭은 **뒤에서 4cm, 라펠에서 6cm**,
> 누임 치수(★)는 **2.5cm**로 설정.

## 확정 수치 (j)

| 항목 | 값 | 테일러드 h 와 비교 |
|---|---|---|
| 칼라 허리 | **3** | 같음 |
| 칼라 폭(뒤) | **4** | 같음 |
| **라펠 폭** | **6** | **h 는 8** |
| 누임 치수 ★ | **2.5** | 같음 |
| 목둘레 이동량 | **1** | 같음 |
| 앞 목둘레선 | **2** | 같음 |
| 앞 중심 올림 | **1** | 같음 |
| 꺾임 끝 옆 | **1.5** | 같음(몸판 앞여밈) |
| 어깨선 연장 | **0.7** | 같음(제도법 상수) |
| 칼라 끝 | **없음** | h 는 정삼각형 3·3·3 |
| 라펠 외형 휨 | **없음** | h 는 0.5 |

## 사진 캡션

> 칼라 허리가 높아 라펠에서 칼라를 향해 칼라 허리가 서고, 옆에서 뒤까지는 목 쪽으로 붙는다.
