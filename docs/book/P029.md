# P.29 — 허리 이음선 Ⓟ (+ P.163 기준점을 잡고 잘라서 벌린다) — [패턴학교]

Ⓟ = **박시 몸판(Ⓐ 의 패턴) + WL 에서 5cm 아래 이음선 + 페플럼(15cm)은 수직 절개 2곳을 벌리고 밑단 옆 +1.5.**
Ⓞ(P.28)와 같은 구조이되 아래가 다르다. 도해 직접 판독(2026-09-30).

| 항목 | Ⓞ(P.28) | Ⓟ(P.29) |
|---|---|---|
| 이음선 | WL | **WL − 5cm** |
| ∅ (잘라서 벌리는 분량) | ● × 0.4 − 2 | **● × 0.3 − 1.5** |
| 밑단 옆 | +2 | **+1.5** |
| 절개 각 ∅/2 | «4 정도» | «3 정도» |
| 절개 | WL 3등분 수직 2곳 | 이음선 3등분 수직 2곳(도해: 3조각) |

**사용자 확정 6건(2026-09-30, 잠긴 설계 결정)**
1. WL~이음선 몸판 옆선은 **수직**.
2. +1.5 는 **이음선 아래 페플럼 구간에만**(몸판 옆선 전체 기울기가 아니다 — `hemSideOffsetCm` 을 쓰지 않는다).
3. ● = **이음선의 완성 둘레**.
4. `seamBelowWaistCm:5` 로 이음선 위치를 확장하되 Ⓜ·Ⓝ·Ⓞ 결과는 **바이트 동일**.
5. 전체 길이 = WL 아래 20cm → 페플럼 15cm.
6. 이음선·밑단은 Ⓞ 처럼 **fairing**.

구현: `designWaistSeam.split(…, {peplumCut: PEPLUM_CUT_P})` = `{ratio:0.3, subtractCm:1.5, cuts:2, seamBelowWaistCm:5, hemSideCm:1.5}`.
`liftSeam` 이 입력 조각을 먼저 고쳐 쓴다(중심·옆선을 이음선 y 에서 분할·waist 선을 이음선으로 이동·밑단 옆 모서리 +1.5).
원래 WL 참고선은 upper construction 에 그대로 남긴다(옆허리 다트 c 의 `attach.root` 가 이 선을 본다 — 없으면 체크포인트 `side-waist-dart-attachment`).
프리셋 `bunka-bodice-P`, body `peplumCut:"P"`(`true` = Ⓞ). 실측(B83·W64): 앞 ●24.447 → ∅5.834(각 2.917 ≈ «3 정도») / 뒤 ●23.053 → ∅5.416(각 2.708).
