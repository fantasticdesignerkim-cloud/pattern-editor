# P.32 — 요크 이음선 ② 변형 Ⓢ «이음선을 넣고 중심에 개더 분량을 추가, 밑단에서 1cm 추가»

## 본문 (한국어 번역본 원문 요지)

- 앞은 AH 다트를 닫는 사정상 **유두점(BP) 부근을 지나는 이음선**을 넣는다.
- **앞 요크는 AH 다트를 닫는다.** 앞뒤 몸판 **중심 쪽에 개더 분량을 평행으로** 추가한다.
- 분량은 **뒤 = ⌀ 의 0.5배, 앞 = ● 의 0.5배.**
- 개더 분량은 천에 따라 조정, **턱으로도 변경 가능.**
- 도해 표시: «□ 는 Ⓐ 의 패턴»(바탕 몸판은 박시 Ⓐ). 밑단 옆 «1» 표기(앞·뒤 모두).
- 사진: 요크는 깔끔하게 몸에 맞고, 개더가 전체적으로 들어가 볼륨감이 있으며 밑단이 살짝 퍼지는 실루엣.
- 꼬리말 참조: 개더 분량 차이 비교 P.102 · 천 차이 비교 P.106 · 닫는다 P.160.

## 구현 시 재사용 가능한 것 (저장소 확인)

- 앞면: `designYokeSeam.splitSide` 의 apex 축 회전·링 분할·`closedDart` 처리·원자성 — 이음선이 apex 에서 꺾이는 기하는 Ⓠ 와 동형.
  **달라지는 부분**: 분할 직선이 수평 `y=Ys` 한 줄이 아니라 `(CF→BP 수평)+(BP→옆 BL−5 사선)` 다중선분.
  `interiorCrossings(seg, Ys)` 기반 교차 로직을 선분 분할 도구로 바꾸거나, 요크/몸판을 이 이음선 polyline 으로 직접 구성하는 경로가 필요.
- 뒤: 수평 BL−5 이음선이라 `y=Ys` 분할이 그대로 맞다(Ys = BL+5). **단 다트가 위쪽에 있으므로 «다트 흡수 회전» 단계를 건너뛰는 분기**가 필요(`dart-not-above-seam` 가정 폐기).
- 개더 띠: `opts.gather` 블록(중심점 평행 이동·`gatherBoundary`·면적/이음길이 검산) 재사용. **띠폭 `Wcm` 만 상수(뒤 10)·식(앞)에서 `이음선 길이 × 0.5` 로 바꾸면 된다.**
- 체크포인트(`bodiceCheckpoint.yokeSeamState`)·`designLayout` 개더 표시·UI(`pendingYokeSeam/Gather`)·프리셋 검증은 body 플래그 방식이라 `yokeSeam:"S"` 류 변형 키 추가로 확장 가능.

## 구현 기록 (2026-10-01)

- 프리셋 `bunka-bodice-S` = body `{ hemExtensionBelowWaistCm: 20, hemSideOffsetCm: 1, yokeSeam: "S" }`(박시 Ⓐ + 밑단 옆 +1). `"S"` 는 개더 띠를 포함한다.
- geometry: BL y = 옆선 변 위 끝(= B/12+13.7 = 20.617). 뒤 이음선 y = BL+5 수평(CB→옆선). 앞 이음선 = CF→BP 수평(BL 높이, BP=AH 다트 apex) + BP→옆선 BL+5 사선.
  앞 AH 다트는 BP 축으로 닫아 요크에 흡수(≈18.25°, 사선이 함께 회전해 요크 이음선이 BP 에서 꺾임·길이 동일). 뒤 어깨 다트는 요크 `construction` 에 원본 다리 두 줄 그대로.
- 개더 띠: 몸판 중심 쪽에만 평행 추가. 폭 = 각 면의 완성 이음선 전체 길이 × 0.5 (앞 25.235→12.618cm · 뒤 23.053→11.527cm). 요크 불변. 몸판 이음 길이 − 요크 이음 길이 = 폭.
- 체크포인트 `yokeRowS` 가 BL·이음선 좌표·다트 보존/흡수·폭을 출력 geometry 에서 독립 재계산한다. hash 에는 뒤 요크 다트 다리(있을 때만)가 반영된다.
- **여전히 미확정(책에 없음)**: 주름 수·모양·턱 치수 — 만들지 않는다. 앞 사선 닫은 뒤 truing 은 패턴선 확정 단계 몫.
