## 종이 공정(구현)

1. 출발 = 완료 몸판 Ⓐ(형상 게이트 — Ⓥ·Ⓦ 와 같음). 뒤 어깨 다트는 **닫지 않고 열린 채** 외곽.
2. 앞: 컷 BP → N(목둘레 위) · 위 조각(목 N~SNP · 어깨 · 위 진동)을 BP 축으로 돌려 AH 입구를 닫는다 → 목에 열린 V(목 다트 = 실제 외곽). 닫힌 AH 다트 다리는 남기지 않는다.
3. 뒤·앞 각각 경사 → 중심선(소매 윗선 · 길이 = SP 에서 중심선을 따라) → ☆ → 밑 안내선 → 팔꿈치 직각 → Ⓒ/Ⓙ → 소맷부리 → 소매 밑선 → Ⓒ→Ⓑ→Ⓓ → 옆선.
4. SP 모서리는 두 변을 2cm 씩 잘라 2차 곡선(G1)으로 다듬는다(관례).
5. 덧천 = 폭선 ø+ø 위 뒤 Ⓑ · 앞 Ⓕ, 아래 꼭짓점 Ⓓ(▣ 두 변), 위 꼭짓점 Ⓒ=Ⓙ(▲ · ※ 두 호의 교점) — 별도 한 장.
