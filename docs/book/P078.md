# P.78 — 테일러드 칼라 h · "3cm의 칼라 허리"

> 판독 완료(수치) · **미구현**. 제도 절차는 [P152.md](P152.md).

## 9교시 머리말(P.79 상단, 그대로)

> 재킷이나 코트에 주로 이용되는 칼라로, 이른바 신사복 칼라. 위 칼라와 라펠로 구성되어 있으며
> 둘의 경계에 깃아귀가 있다. 칼라 허리의 높이나 칼라 폭, 누임 치수에 따라 느낌이 달라진다.
> **여기서는 칼라 폭은 일정하게 두고, 칼라 허리의 높이와 누임 치수를 변경한 2종류를 소개한다.**

★ 즉 **h·i 는 같은 제도(P.152)에 수치 2개만 다르다** — 세일러 U·V·W, 보 X·Y·Z 와 같은 구조.

## 본문(그대로)

> 테일러드 칼라의 기본형. **몸판의 목둘레, 라펠, 위 칼라의 순으로 제도한다.**
> 꺾임 끝은 **BL과 WL 사이를 2등분한 위치**로
> 칼라 폭은 **뒤에서 4cm, 라펠에서 8cm**, 각진 부분은 **3cm**, 누임 치수(★)는 **2.5cm**로 설정한다.

## 확정 수치 (h)

| 항목 | 값 | 어디서 |
|---|---|---|
| 칼라 허리 | **3** | 4-❶ 뒤 중심선 위, 뒤 칼라 달림선에 직각 |
| 칼라 폭(뒤) | **4** | 4-❶ 칼라 허리 다음 |
| 라펠 폭 | **8** | 2-❶ 꺾임선에 직각 |
| 누임 치수 ★ | **2.5** | 3-❷ Ⓑ에서 SP 방향 |
| 각진 부분(칼라 끝) | **3 · 3 · 3** | 5-❶ 반지름 3 원 교점 작도 |
| 라펠 외형 | **0.5** | 2-❸ 완만한 곡선의 휨 |
| 앞 목둘레선 | **2** | 2-❹ |
| 앞 중심 올림 | **1** | 1-❻ FNP 에서 수직 |
| 꺾임 끝 옆 | **1.5** | 꺾임 끝(BL~WL 2등분) 표기 |
| 1-❷ 어깨선 연장(고정) | **0.7** | SNP 에서 어깨선 연장 방향 · h·i 공통 |
| 1-❷ 목둘레 이동량 | **1** | (i 는 0.6) |
| 1-❸ 칼라 허리 잡기 | **2.3** | = 칼라 허리 3 − 0.7 |

## 사진 캡션

> 칼라 허리가 높아 라펠에서 위 칼라를 향해 칼라 허리가 서고, 옆에서 뒤까지는 목 쪽으로 붙는다.
> (SIDE) 칼라 허리가 높아 목이 보이는 부분이 적다.

## 몸판에서 필요한 것 (실측 확인)

- **WL** = `bodiceResult` outline 의 `edge:"waist"`
- **BL** = 진동밑점 U 의 y (`armhole × side-seam` 접점). `semantics.darts` 의 `front-bust` apex y 와 일치
- **꺾임 끝** = 위 둘의 중점
- SNP·FNP·어깨선·앞 중심선 = 의미 모서리에서 직접
