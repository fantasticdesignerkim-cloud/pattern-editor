# P.75 — 후드 e · "Ⓓ의 응용으로 중심에 덧천을 끼운다"

> 판독 완료 · **미구현**(catalog `bunka-hood-e` = `pending-source`).
> 기본 제도는 [P151.md](P151.md)(d) 를 따른다.

## 본문(그대로)

> **Ⓓ의 응용으로 중심에 덧천을 끼운다**
>
> Ⓓ 제도의 중심에서 덧천 폭을 잘라서 이음선을 그리고, **이음선과 같은 치수로 덧천을 그린다.**
> 덧천은 **뒷머리부터 뒤 목둘레까지의 폭을 서서히 좁히면서** 균형을 맞춘다.

사진 캡션: "Ⓓ에서 보이는 삼각의 뾰족함이 없어지고 머리 모양을 따르는 실루엣. 입체감을 살려 덧천의
앞 끝 주변이 머리에서 조금 떨어진다."

## 도해 판독

- 위쪽에 별도 조각 **"덧천"** 이 따로 그려져 있다 — 왼쪽 끝 **3**, 오른쪽 끝 **5**(폭).
- 후드 조각에는 d 의 윤곽선이 점선("후드 Ⓓ의 윤곽선")으로 겹쳐 있고, 중심에서 잘라낸 **이음선**이
  실선으로 들어간다. 이음선 쪽 표기 **5**(위) / **3**(아래, 뒤 목둘레 쪽).
- **∅ · ● 기호**가 이음선과 덧천의 대응 구간이 같은 치수임을 표시한다.

## 미구현 사유(무엇이 d 와 다른가)

**덧천이 별도 조각**이다. 현재 `collarDraft` 는 카라 한 종류당 **조각 하나 + construction** 만 담는
모델이라, 조각을 하나 더 두는 **데이터 모델 확장**이 먼저 필요하다.

## 확정 안 된 것

- 덧천 폭 5→3 이 **반폭인지 전체 폭인지**(후드가 반쪽 패턴 2장 + 덧천 1장 구성이라 갈린다).
- 폭이 5 에서 3 으로 좁아지는 **구간 경계**("뒷머리부터 뒤 목둘레까지"가 d 의 어느 점들인지).
