# P.28 — 허리 이음선 Ⓞ (+ P.163 기준점을 잡고 잘라서 벌린다) — [패턴학교]

Ⓞ = **박시 몸판(Ⓐ 의 패턴) + 허리 이음선 + 페플럼은 허리 쪽을 기준점으로 잘라서 벌리고 밑단에서 플레어 분량을 넣는다.**
플레어 분량은 허리 완성 치수의 **0.4배**. (Ⓟ P.29 는 같은 구조: 허리에서 5cm 아래 이음선 · ×0.3 − 1.5 · 밑단 +1.5.)

원본 도해 직접 판독(2026-09-29):
- 몸판: "▯는 Ⓐ의 패턴". 허리 다트는 그려져 있지 않고(앞 AH·뒤 어깨 다트만), 옆선은 WL 까지 수직. **사용자 확정: 허리 다트 a·b·d·e 제거·옆선 −1.5 없음.**
- 절개: 페플럼(WL~밑단)에 **WL 을 3등분한 점**(화살표 끝)에서 **수직 절개 2곳**(앞·뒤 동일). 화살표 = P.163 의 기준점.
- 산식(도해): `잘라서 벌리는 분량(∅) = ● × 0.4 − 2`, ●= 앞(뒤) 완성 허리. 물결 밑줄 = 플레어 분량, −2 = 옆 밑단 +2. 절개 2곳 각 ∅/2 (도해 «4 정도»).
- 절개 그림: 3조각이 부채꼴. **앞중심 쪽 조각 고정**, 나머지는 바깥으로 순차 회전, 벌어진 틈은 밑단 쪽에만. 허리선·밑단 모두 매끈한 호. WL 위 점선 소곡선 = 벌린 뒤 허리선 정리 표시(**사용자 확정**).
- P.163: 기준점(화살표)을 연필로 고정하고 종이를 회전해 한쪽만 벌린다. 처리한 곳은 각지지 않게 완만한 곡선. 벌림 치수(8)는 밑단 끝 사이 간격.

**사용자 확정 해석(2026-09-29)**: 몸판 박시(허리 다트 a·b·d·e 없음, 옆선 수직, AH·어깨 다트 유지) / 허리선·밑단 모두 fairing / chord 벌림(Ⓝ 과 동일).

구현: `designWaistSeam.split(…, {peplumCut:{ratio:0.4,subtractCm:2,cuts:2}})` → `buildPeplum` 이 다트 없는 페플럼에서
WL 등분점 절개(폭 0)를 합성해 `designJoin.buttSpread` 를 순차 호출 + `fairWaistRun`(허리 꺾임을 중점~중점 G1 블렌드).
허리 fairing 이 길이를 줄이므로(앞 0.051 · 뒤 0.042cm) 몸판 봉제 허리 − 페플럼 허리 = 이 감소량이어야 정합으로 본다.
