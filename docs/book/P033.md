## 본문 (한국어 번역본 원문 요지)

- 이음선을 넣는 법, 즉 **요크의 모양은 Ⓢ 와 동일**하다.
- 앞뒤 몸판에 **절개선을 넣어 요크 쪽을 기준점으로 밑단을 잘라서 벌린다**(처리 방법 P.163 «기준점을 잡고 잘라서 벌린다»).
- **플레어 분량은 Ⓐ 의 가슴 완성 치수의 0.5배.** 절개 분량을 늘리면 플레어도 풍성해진다.
- 계산식(절개 그림 아래): **잘라서 벌리는 분량 ∅ = ● × 0.5 − 2.5**. 물결 밑줄 «●×0.5» 가 «플레어 분량»(= 총 분량), **«−2.5» 는 밑단 옆 +2.5 가 이미 차지한 몫**(분홍색으로 «2.5» 가 밑단 옆 표기와 짝). **뒤도 같은 방법으로 계산해 잘라서 벌린다.**
- 절개 그림: 절개 **2곳**, 각 곳의 밑단 벌림 = **∅/2**(«5 정도» 표기 → ∅≈10, ●≈25).
- 패턴 닫는 법(P.160): 앞 AH 다트를 닫은 «앞 요크»(Ⓢ 와 동일).
- 사진 캡션: **Ⓖ(P.20)에 가까운 밑단이 퍼지는 실루엣. 이음선을 넣어 요크는 몸에 맞고 밑단 쪽만 플레어가 들어간다.**
- 꼬리말 참조: 플레어 분량 차이 비교 P.104 · 천 차이 비교 P.107 · 닫는다 P.160 · 기준점을 잡고 잘라서 벌린다 P.163.

## Ⓢ ↔ Ⓣ 차이

| | Ⓢ(P.32) | **Ⓣ(P.33)** |
|---|---|---|
| 요크·이음선·다트 처리 | BL−5 / 앞 BP 꺾임 / 앞 흡수 · 뒤 어깨 다트 보존 | **동일** |
| 분량 방식 | 중심 평행 개더 띠(폭 = 이음선 길이 × 0.5) | **수직 절개 2곳 밑단 벌림(총 ∅ = ●×0.5 − 2.5)** |
| 밑단 옆 | +1 | **+2.5** |
| 몸판 이음선 | 원래 모양 그대로 + 개더 띠 윗변 | 원래 모양 → **절개점에서 꺾임**(벌림 회전) · fairing 필요 |
| 몸판 조각 | 중심 개더 띠가 붙은 한 장 | 벌린 한 장(조각 3개 맞댐) |

## 구현 시 재사용 가능한 것 (저장소 확인)

- **요크 전부**: `designYokeSeam.splitSideS` — 요크·몸판 분리·앞 다트 흡수·뒤 다트 보존·검산이 그대로 맞다. `gatherBand`(8단계)만 건너뛰는 분기(`opts.gather:false` 류)가 필요.
- **절개 벌림**: `designJoin.buttSpread`(chord·pivot·bridge `smooth/hem`) 그대로. `designWaistSeam.buildPeplum` 의 `cut` 분기(WL 등분 → 수직 절개 → 조각 strip → 순차 spread → 밑단 fairing)와 동형이지만 **WL 이 외곽선 모서리인 페플럼 전용**이라 그대로는 못 쓴다(고정점이 «허리 입 점», 여기는 «이음선 교점»).
- 프리셋·검증: `bunkaPresets` 의 `yokeSeam:"S"` 확장 패턴, `peplumCut` 플래그의 ratio/subtract/cuts 상수 패턴.
