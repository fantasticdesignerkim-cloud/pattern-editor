## 원본에서 직접 읽히는 것 (원문 요지)

- 머리말: 어깨를 감싸는 어깨 요크, 어깨선에서 맞대어 앞뒤를 연결. 이음선에 개더·턱을 넣을 때 **개더 끝은 진동 둘레선에서 약간 떼어 놓는다**(→ 양 끝 «2»).
- 제목 «Ⓤ 방법 + 앞뒤에서 개더 분량을 추가». 본문 3줄:
  1. «앞은 AH 다트를 닫고, **다트 끝에서 수직으로 절개선**을 넣어 **평행으로 벌린다**.»
  2. «뒤 몸판은 개더 분량을 **뒤 중심에서** 추가한다.»
  3. «개더 분량은 **뒤는 ∅ 의 1배, 앞은 ● 의 1.2배**.» (Ⓤ 는 뒤 ∅×0.5 · 앞 ●×약 0.6)
- 꼬리말: 개더 분량 비교 P.102 · 천 비교 P.106 · 2곳 이상 맞댄다 P.159 · **닫는다 P.160 · 평행으로 잘라서 벌린다 P.162**
  (⚠ P.34 꼬리말의 «닫는다·벌린다 P.161» 과 쪽이 다르다 — 이 쪽은 닫기와 벌림을 따로 가리킨다).
- 도해 4종: 뒤 / 앞(닫기 전, 「닫는다」·「잘라서 벌린다」) / **맞댄 그림**(«어깨 요크» = Ⓤ 와 동일) / **절개 그림**(앞).
- 밑단 옆 앞·뒤 **«1»**(Ⓤ 와 동일). 앞 이음선 **«6»**, 양 끝 **«2»**, 뒤 진동 쪽 **«2»**(Ⓤ 와 동일).

## 단계별 제도 순서 (Ⓤ 와 같은 것 → Ⓥ 에서 달라지는 것)

**Ⓤ 에서 그대로 재사용(도해가 Ⓤ 와 같다)**
1. 뒤 어깨 다트를 먼저 닫고 앞 요크와 어깨선에서 맞대어 «어깨 요크» 한 장.
2. 앞 이음선 = 어깨선 평행·수직거리 6 · 진동선→목둘레선 · 호길이 1/2점 T · BP→T 직선 · AH 다트를 BP 축으로 닫아 이음선에 쐐기. 앞 «2» 양 끝 제외.
3. 뒤 이음선 = 다트 끝 높이 수평 · 중심 쪽 세로 띠(요크 불변) · 밑단 +1 · ∅ = 이음선 − 2.

**Ⓥ 에서 새로 생기는 것**
4. **BP 에서 밑단까지 앞중심선과 평행한 수직 절개선**(본문 «다트 끝에서 수직으로»). 시작 = BP, 끝 = 밑단선(절개 그림에서 띠가 밑단까지 관통).
5. **앞중심 쪽 조각을 «평행으로» 옆(바깥)으로 d 만큼 이동**(P.162: 절개선에 **직각**으로 분량을 끼움 → 수직 절개이므로 수평 이동). 닫힌 AH 쐐기(진동 쪽 조각의 BP 회전)는 그대로 둔다. 절개 도해에서 CF 쪽 조각의 위 절개선(BP→T, 연직에서 약 5.4° 기움 — Ⓤ 구현값)은 평행 이동되어 앞 이음선이 쐐기 + 평행 벌림만큼 길어진다.
6. 이음선은 끊긴 모서리를 완만히 다시 그린다(P.162 ⑥ 주석 «각지지 않게 완만한 곡선으로 수정»).
7. **뒤**: 중심 띠 폭 = **∅ × 1**(Ⓤ 는 ×0.5). 뒤 도해에서 ∅ 호 둘 — 새 중심선→원래 CB, 원래 CB→진동 쪽 «2» 앞 — 의 길이가 같다(화소 실측 370:375).

## ● · ∅ · «5 정도» 판독 (원본 기호 / 계산 해석을 분리)

| | 원본 | 계산(B=83 · Ⓤ 엔진 실측) |
|---|---|---|
| ∅ (뒤) | 원래 CB → 이음선 끝 **«2» 앞**까지의 호 | 이음선 18.580 − 2 = **16.580** → 띠 폭 = ∅×1 = **16.580**(Ⓤ 는 8.290) |
| ● (앞) | 두 «2» 사이의 이음선 호(개더 구간) — 절개 도해의 «●×1.2» 원호는 **벌어진 전 구간**을 감싼다 | 이음선(요크) 12.965 − 4 = **8.965** |
| 앞 개더 분량 | **«앞은 ● 의 1.2배»** = 몸판 이음선이 요크 이음선보다 긴 **총 초과분** | 1.2×8.965 = **10.758** |
| AH 쐐기(Ⓤ 에서 이미 생김) | Ⓤ 캡션 «● 의 약 0.6배» | 5.391(= 0.6014●) |
| **«5 정도»** | 절개 도해 밑단 쪽 **띠 폭에 붙은 괄호 «(5 정도)»** — «정도» = 참고치 | 총 10.758 − 쐐기 5.391 = **d ≈ 5.37** → **고정 5cm 가 아니라 계산 결과의 참고치** |

근거: ① «●×1.2» 원호가 쐐기만이 아니라 평행 띠까지 포함한 전체 틈을 감싼다(도해 틈 250px : 띠 115px → 10.758×115/250 = 4.95cm ≈ «5»). ② 총량이 1.2● 일 때만 d ≈ 5 가 나온다 — (●=쐐기)로 읽으면 d=1.1, (1.2●가 추가분)이면 d=10.8 이라 도해와 맞지 않는다. ③ Ⓤ 가 이미 쐐기 = 0.6●, 따라서 Ⓥ 는 정확히 **쐐기 0.6● + 평행 벌림 0.6● = 1.2●** 로 Ⓤ 의 2배 — 뒤도 ×0.5 → ×1 로 2배(앞뒤 균형, 본문 «Ⓤ 방법 + 개더 추가»).

## 책에 없는 값 / 구현 때 정해야 하는 것(미확정으로 둔다)

1. **d 의 정의**: «개더 분량 = 이음선 초과분 = 1.2●» 이므로 d 는 `|T+(d,0)−T'|` 로부터의 초과분이 1.2● 가 되게 푼다(근사 d = 1.2●−쐐기 현 = 5.37, 정확해 ≈ 5.45). 정확해 vs 근사는 책에 없다 — **정확해를 권고**(체크가 길이 초과분으로 닫히기 때문). «5 정도» 는 검증 게이트가 아니라 감시 비율.
2. 이음선 재작도: 도해의 굵은 선은 쐐기+벌림 위를 **한 직선**으로 잇는다. 형태(체인 vs 직선 vs fairing)는 책에 길이 규칙이 없다 → Ⓤ 와 같은 «체인(쐐기 현 + 이동 현)» + Ⓣ 의 `fairSeamRun`(길이 보존 fairing) 재사용을 제안. 어느 쪽이든 길이 초과분 = 1.2● 를 지킨다.
3. 수직 절개선이 가로지르는 **허리 다트 a/b 구성선**: 책 도해(Ⓐ 박시)에는 허리 다트가 없다 → Ⓤ 처럼 이음선 아래 구성선 보존 + 절개선과 교차하는 선은 `droppedConstruction` 에 기록(교차선 처리는 검증 대상).
4. 이동 조각이 CF 쪽(= 앞중심 접힘선 포함) 인지 옆선 쪽인지는 기하적으로 동치(평행이동). 구현은 Ⓤ 처럼 **옆 조각 고정 · CF 쪽 조각 이동**(CF 가 바깥으로 d 만큼 나가 앞 폭이 d 늘어난다 — 도해와 일치).
5. 주름 수·턱 형상: 도해에 없다 → 만들지 않는다(개더는 길이 초과분 + 점선 표기만).
