## 책에서 확정되는 것

- 본문: «허리선에서 약간 가늘어지도록 이음선과 옆선에서 조금씩 줄인다. 이용하는 허리 다트 a, e 를 **옆쪽으로 이동**해 선의 흐름이 아름답다. 균형을 생각해 옆선도 1cm 줄인다.»
  사진 캡션: «Ⓒ 와 같은 분량으로 줄이므로 셰이프트 라인과 같은 실루엣».
  → **몸판 파라미터는 Ⓒ 와 동일**: a·e / 옆선 −1 / 밑단 +1 (`waistDartScales` 도 Ⓒ 와 같다). 새 엔진 변수 없음.
- 조각: 앞 = **앞중심 조각 + 앞·옆 조각**, 뒤 = **뒤중심 조각 + 뒤·옆 조각** → **최종 4조각.** 꼬리말 «닫는다…P.160».
- **어떤 다트를 닫나 (P.160 이 Ⓔ 로 직접 설명)**: **앞 AH 다트만 닫는다.** 앞·옆 조각의 AH 다트 아래 부분을 본뜨고, **다트 끝(BP)을 고정**해
  종이를 회전시켜 AH 다트 위쪽 선에 겹친 뒤 나머지를 본뜬다 → «AH 다트를 닫은 앞·옆 패턴 완성». 회전각 = 기존 AH 다트각(앞 기본 18.25°).
  닫힌 자리는 흔적을 남기지 않는다(점선 = 참고선). 처리한 곳은 «각지지 않게 완만한 곡선으로 수정».
- **절개선(이음선) 형태(도해 판독)**: 앞 = 어깨선 위 한 점 → **BP 를 지나** → 허리 다트 a 를 끼고(다트가 이음선 안으로 들어가 **마름모**) → 밑단.
  어깨→BP 구간은 직선 안내선과 곡선이 나란히 그려지고 둘 사이 최대 간격에 **«0.5»**. 뒤 = 어깨 다트 입구에서 시작 → 다트 끝 근처를 지나 → 허리 e(마름모, 라벨 «e»·«e» 둘) → 밑단.
- 어깨선 끝에 ● 표시 + 파선 호(컴퍼스): 닫은 뒤 어깨선을 같은 길이(●)로 다시 그린다는 표시.

## ★ 열린 질문 — 책에 없는 패턴 원리 선택 (구현 보류, `blockedBy`)

책이 정하지 않는 것: ① **앞 어깨 절개 시작점**(수치 없음, 도해상 약 50%) ② 어깨→BP **«0.5» 곡선의 방향·소유 조각**과 BP→밑단 곡선 형태
③ **a·e 를 «옆쪽으로 이동»하는 양**과 뒤 이음선이 어깨 다트의 어느 다리를 따르는지 ④ 닫은 뒤 **어깨선 ● 재작도** 규칙.
위 넷은 서로 묶여(이음선 한 줄의 정의) 개별로 답할 수 없으므로 **한 질문**으로 묶는다: *이음선을 어떻게 정의할 것인가* — 선택지는 최종 보고 참고.
