## 책에서 확정되는 것

- 본문: «허리선에서 약간 가늘어지도록 이음선과 옆선에서 조금씩 줄인다. 이용하는 허리 다트 a, e 를 **옆쪽으로 이동**해 선의 흐름이 아름답다. 균형을 생각해 옆선도 1cm 줄인다.»
  사진 캡션: «Ⓒ 와 같은 분량으로 줄이므로 셰이프트 라인과 같은 실루엣».
  → **몸판 파라미터는 Ⓒ 와 동일**: a·e / 옆선 −1 / 밑단 +1 (`waistDartScales` 도 Ⓒ 와 같다). 새 엔진 변수 없음.
- 조각: 앞 = **앞중심 조각 + 앞·옆 조각**, 뒤 = **뒤중심 조각 + 뒤·옆 조각** → **최종 4조각.** 꼬리말 «닫는다…P.160».
- **어떤 다트를 닫나 (P.160 이 Ⓔ 로 직접 설명)**: **앞 AH 다트만 닫는다.** 앞·옆 조각의 AH 다트 아래 부분을 본뜨고, **다트 끝(BP)을 고정**해
  종이를 회전시켜 AH 다트 위쪽 선에 겹친 뒤 나머지를 본뜬다 → «AH 다트를 닫은 앞·옆 패턴 완성». 회전각 = 기존 AH 다트각(앞 기본 18.25°).
  닫힌 자리는 흔적을 남기지 않는다(점선 = 참고선). 처리한 곳은 «각지지 않게 완만한 곡선으로 수정».
- **절개선(이음선) 형태(도해 판독)**: 앞 = 어깨선 위 한 점 → **BP 를 지나** → 허리 다트 a 를 끼고(다트가 이음선 안으로 들어가 **마름모**) → 밑단.
  어깨→BP 구간은 직선 안내선과 곡선이 나란히 그려지고 둘 사이 최대 간격에 **«0.5»**. 뒤 = 어깨 다트 입구에서 시작 → 다트 끝 근처를 지나 → 허리 e(마름모, 라벨 «e»·«e» 둘) → 밑단.
- 어깨선 끝에 ● 표시 + 파선 호(컴퍼스): 닫은 뒤 어깨선을 같은 길이(●)로 다시 그린다는 표시.

## ★ 사용자 확정 (2026-10-03, A안 — 도해 실측 기준, 더 이상 질문·해석이 아니다)

1. **앞 어깨 절개 시작점 = 목점(NP)에서 어깨선 호길이 50%.** B83 에서 6.140cm(어깨 12.280cm).
2. **어깨→BP 이음선 = 기준 직선(시작점→BP)에서 도해 방향(앞중심 반대 = 진동 쪽)으로 최대 0.5cm 볼록한 완만한 곡선.** 구현: 대칭 제어점 3차 베지어, 최대 편차 정확히 0.5cm(중점), 반대편 편차 0.
3. **뒤 이음선 = 기존 어깨 다트 입구에서 시작.** 중심 조각은 중심 쪽 다리, 옆 조각은 진동 쪽 다리를 이음선으로 갖고(다트가 이음선에 흡수), 다트 끝 아래는 한 개의 수직선.
4. **허리 다트 a·e 마름모는 이음선 축에 맞춘다.** 축 x = 위쪽 다트 끝의 x(앞 BP · 뒤 어깨 다트 끝). 앞 a 는 이미 같은 x(이동 0), 뒤 e 는 옆쪽으로 0.5cm 이동. 마름모는 다트 끝 → WL 에서 다트 폭(a 1.75 · e 2.25cm) → 밑단 축 위 한 점에서 닫힌다.
5. **닫는다 = 앞 AH 다트만, BP 고정 기본 다트각 18.25° 로.** 옆 조각의 BP 위쪽(어깨·진동 윗부분·이음선 윗부분)이 회전하고 아래쪽은 제자리(P.160 «나머지를 본뜬다»). 닫힌 V 의 두 다리는 남기지 않는다. 앞/뒤 각각 중심·옆 2조각 = **총 4조각**.
6. **닫힌 뒤 어깨선은 끊김 없는 봉제선으로.** 구현 해석(검산으로 고정): 강체 회전은 어깨 길이·각도를 보존하므로 봉제 정렬 프레임(옆 조각 윗부분을 BP 축으로 되돌려 이음선을 맞춘 상태)에서 중심·옆 어깨선은 **한 직선(꺾임 0)** 이고 길이 합 = 원래 어깨(12.280cm). 닫은 평면 배치에서 옆 조각 어깨 끝이 7.26cm 벌어져 보이는 것은 AH 다트 분량이 이음선으로 옮겨 간 결과다(조각이 분리돼 있어 찢김·겹침 없음).
