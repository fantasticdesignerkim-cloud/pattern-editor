# P.27 — 허리 이음선 Ⓝ (+ P.158 맞대면서 벌린다) — [패턴학교]

Ⓝ = **Ⓜ 방법 + 페플럼은 허리선에서 맞대어 밑단에 플레어 분량을 넣는다.** 플레어 분량은 허리 완성 치수의 0.9배.

- 공식(도해): `잘라서 벌리는 분량(∅) = (● + ■) × 0.9 − 1`. ● · ■ = 맞댄 뒤 허리선의 두 구간 표기
  → **사용자 확정(2026-09-29): ●+■ = 앞·뒤 페플럼 각각의 완성 허리길이**, −1 은 계산값에서 차감.
- 도해: 절개 2곳, 각 **∅/2 (5 정도)**. «5 정도» 는 참고 결과(고정값 아님).
- 몸판: Ⓜ 과 같다(옆 −1.5 · 밑단 +1 · b(앞)·d(뒤) 닫음, a·e 유지).
- P.158 절차: ① 제도 ② 다른 용지를 겹쳐 앞중심 쪽 Ⓐ 를 베낀다 ③ **WL 의 포인트를 고정**하고 종이를 회전해 지정 치수를
  벌린다 ④ 중심 부분 Ⓑ ⑤ 옆쪽 Ⓒ 를 같은 방법으로 ⑥ 맞대면서 벌린 페플럼 완성 — **처리한 곳은 각지지 않게 완만한 곡선**.
