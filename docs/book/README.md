# 교재 판독 노트 — 『パターン製作の基礎』(패턴학교 상의편)

## 왜 있나 (읽기 전에 이것부터)

**원본 PDF 621MB 는 토큰을 먹지 않는다.** PDF 는 컨텍스트에 올라가지 않고 `tools/bookpage.py` 가
Bash 에서 꺼내 쓴다. 토큰을 먹는 건 **도해 이미지를 `Read` 로 여는 횟수**다(한 장 열 때마다 비용이 들고,
숫자를 읽으려면 확대 크롭을 여러 장 더 열어야 한다 — 후드 d 판독에 이미지 10장이 들었다).

그래서 이 폴더의 목적은 하나다: **같은 페이지를 두 번 다시 열지 않는 것.**
판독이 끝난 페이지는 확정 수치·제도 절차·미확정 항목을 여기 글로 남기고, 다음 세션은 이미지 대신 이걸 읽는다.

## 규칙 (위반 금지)

1. **이 노트를 `CLAUDE.md` 에 옮기지 않는다.** `CLAUDE.md` 는 매 세션 통째로 컨텍스트에 올라가므로,
   그 칼라를 건드리지 않는 세션까지 비용을 낸다. 여기 파일은 **필요할 때만 읽는다**(온디맨드).
2. **이미지는 커밋하지 않는다.** `books/`·`books/pages/` 는 교재 원본이라 **미추적 보존**
   (`armhole_data_*.json`·`AGENTS.md` 와 같은 취급). 노트(수치·절차 요약)만 커밋한다.
3. **노트는 실제로 읽은 페이지만 쓴다.** 추측으로 채우지 않는다. 확정되지 않은 표기는
   "미확정"으로 남기고, 무엇이 확정돼야 좌표로 옮길 수 있는지를 적는다.
4. **실행 수치의 단일 진실은 노트가 아니라 `js/collarPresets.js` 의 레코드다.** 노트는 판독 근거·절차이고,
   형상을 만드는 값은 레코드에서만 읽는다. 둘이 어긋나면 레코드를 고치고 노트에 사유를 남긴다.

## 페이지 오프셋 (실측 확정)

**책 P.N = PDF index N−1.** 근거: PDF index 70 의 인쇄 쪽번호가 71(보 칼라), index 71 이 72(프릴 칼라).
`tools/bookpage.py` 가 이 오프셋을 코드에 담고 있으니 직접 계산하지 말고 도구를 쓴다.

## 도구

```bash
python3 tools/bookpage.py split            # 176쪽 전부 분할(1회, ~60초)
python3 tools/bookpage.py page 151         # 책 151쪽만
python3 tools/bookpage.py crop 151 0.55 0.05 1.0 0.40 2   # 비율 크롭 + 2배 확대(숫자 판독용)
```

산출물(전부 미추적):
- `books/pages/pNNN.jpg` — 원본 해상도(약 4824×6550). **숫자를 읽을 때는 이쪽을 크롭해서 확대**한다.
- `books/pages/small/pNNN.jpg` — 1/4 축소(1206×1637). **전체 레이아웃 파악용**. 작은 치수는 안 읽힌다.

판독 순서 권장: `small` 로 페이지 구성을 먼저 잡고 → 숫자가 필요한 영역만 `crop` 으로 확대. 이러면
이미지 열기 횟수가 줄어든다.

## 무엇이 어디 있나

- `INDEX.md` — 페이지 → 주제 → 구현 상태 → 프리셋 id. **어느 노트를 열지 고르는 용도.**
- `P0NN.md` / `P1NN.md` — 페이지별 판독 노트. 판독을 마친 페이지만 존재한다.
