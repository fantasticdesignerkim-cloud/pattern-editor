### 본문·도해(F)

- 본문: 조금 긴 프렌치 슬리브. **몸판 어깨선을 연장**해 거기부터 **직각**으로, 그다음 **완만한 곡선으로 옆선에 연결**.
  **소맷부리 치수를 확보하기 위해 어깨 끝 경사는 두지 않는다**(Ⓨ 의 0.5 내림 없음). 예는 **앞 AH 다트를 옆으로** 이동.
- 도해 치수(앞뒤 대조):
  - **12** = 원래 SP 에서 어깨선 연장 끝 E 까지(뒤·앞 같음). E 에 직각 표시(연장선과 소맷부리선의 직각).
  - **가는 직선** = E → **C**(원래 진동 아랫점 = 원래 옆선 위 끝 · 앞은 다트 이동 뒤 아랫점). 흰 덧종이의 왼쪽 경계가 원래 진동.
  - **0.7(뒤) / 0.3(앞)** = 소맷부리 곡선이 가는 직선 E–C 에서 **바깥으로** 가장 멀어진 거리. 직각 출발 방향과 E–C 의 각이
    뒤가 크고 앞이 작아서(B83 실측 뒤 12.55° / 앞 5.47° — 도해 픽셀 보조 판독 ≈ 12.8° / 5°) 뒤가 더 부푼다.
  - **2.5** = C 에서 가는 직선을 따라 위로 = **T**(곡선이 직선에 닿는 점). **2** = C 에서 옆선을 따라 아래로 = **H**(«소맷부리 끝» 화살표).
    → C 모서리를 두 다리(2.5 · 2)로 둥글리는 표기. 곡선은 H 에서 옆선에 접선으로 이어진다.
  - 앞: 옆 다트(위 다리가 H 바로 아래) · 점선 = 원래 AH 다트 자리(BP 까지). 뒤: 어깨 다트 열린 채.
- 사진 문구: 입으면 어깨 끝에서 소매로 가는 경사가 자연스럽고 어깨 끝을 완벽히 커버. 옆 사진의 팔구멍 아래 끝이 뾰족하다.
- **Ⓨ 와 다른 점**: Ⓨ 는 원래 진동에 **합류**(J · 진동 아랫점에서 호 3 — 관례)하고 겨드랑이·옆선은 원래 그대로. Ⓩ 는 원래 진동에 합류하지 않고
  **원래 진동 전체와 옆선 위 C→H(2) 를 덮어 옆선으로 이어진다**. Ⓨ 의 호 3 · 내림 0.5 는 승계하지 않는다.
