## 재단 — 수량·좌우 쌍·기본 표시선 (2026-11-20 김님 확정 · v2026.11.20.3 · 미커밋)

- **수량 기본 전부 1.** 좌우가 있는 조각 = 앞판·소매(`sleeve-…`)·커프스 → 수량 1 = «왼 1 + 오른 1» 거울 쌍(`pairingOf` → `pairOne`; 거울 id = 원본 id + `~m`, 저장 키는 원본 id 하나). 골 조각(뒤판·칼라·밴드)은 골 1장. 수량을 1 이 아닌 값으로 직접 정하면 쌍으로 펼치지 않고 그 수량 그대로 한 조각(의미 추정 없음). 옛 «앞판 2 = 쌍» 저장값은 이제 «한 조각 2장»으로 읽힌다.
- 소매·커프스의 좌우 이름은 **관례**(원본 = 오른쪽, 반사 = 왼쪽) — 앞판만 앞중심 위치로 판정한다. 틀리면 `pairOne` 한 곳을 고친다.
- **기본 표시선**(`guidesOf` · 조각 모델 `r.guides` 한 벌을 화면·인쇄·DXF 가 읽는다): 앞판 `C.F` · 뒤판 `C.B`(이미 그려지는 앞중심 표시·골선이 있으면 글자만) · 가슴선(= 옆선 위끝 `blYOf`) · 허리선(= 원형 기준 형상 outline 의 `waist` 변 y — `derive().refY`). 일반 DXF = 선 INTERNAL · 글자 TEXT / AAMA = 선 레이어 8 · 글자 레이어 15. 인쇄 클래스 `cp-gline`(`cp-guide` 는 안내 쪽 이름이라 쓰지 않는다).
